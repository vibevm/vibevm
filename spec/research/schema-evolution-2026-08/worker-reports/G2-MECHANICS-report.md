## Decisions taken (each with why)
- Avro признан ДОРОЖЕ -> предпосылка «схема и данные в одной истории git»
  неверна (каталог и Rust-типы — два репозитория), а внешний читатель без репо и
  скопированная запись ломают разрешение схем целиком.
- Различимость списков признана ненужной для каталога -> машинные поля
  детерминированно вычисляются, «отсутствует» не бывает легитимным состоянием.
- Форма A (тег-поле) выбрана рекомендованной -> один атрибут от нынешнего
  состояния, выразима во всех языках схем, и устраняет блокер А6, который держит
  только `#[serde(untagged)]`.
- Несоответствие типа отнесено к твёрдому отказу -> коэрция = патология «будь
  либерален» (RFC 9413); это порча, не эволюция.
- Rename-безопасность через `#[serde(alias)]` -> бесплатна в serde, работает и в
  JSON, и в TOML; один список отставленных имён (рекомендация свода) недостаточен.

## С чем я не согласен
1. **Avro «почти бесплатно» — не согласен (предпосылка ложна).** Каталог и схема
   в двух разных репозиториях/историях; внешний читатель без репо и
   скопированная запись ломают модель; Avro ДОРОЖЕ терпимого читателя, который уже
   написан (`wire.rs`).
2. **«Угадывание по набору ключей» — не согласен с фактикой.** `Directory` уже
   несёт `kind:"directory"` (`repomd.rs:44-50`); дефект — `untagged`, не отсутствие
   дискриминанта.
3. **«14 полей» — не согласен с периметром.** Живое число — 21; структурные поля
   с `*Entry::is_empty` коллапсируют пусто≡отсутствует так же; решение А6
   принято по заниженному числу.
4. **«Невосстановление присутствия списков = незавершённость» — не согласен.**
   Это осознанный отказ; для каталога различимость не нужна (машинные поля не
   бывают «неизвестными»).
5. **«Наследуем проблемы JSON-protobuf без выхода» — не согласен с рамкой.**
   Наш выход — убрать `deny_unknown_fields` (один атрибут), а не двоичный формат;
   скалярного коллапса proto3 у нас в JSON нет вовсе.
6. **Поле-имя — возмещаемо полностью, а свод назвал только полумеру.** Список
   отставленных имён необходим, но rename-безопасность даёт `#[serde(alias)]`,
   которого свод не упомянул.
