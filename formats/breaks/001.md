# Break 001 — `repomd.json`: the `files` union becomes symmetrically tagged

**Date:** 2026-08-14 · **Format:** `index-repomd` · **Epoch:** 1 (unchanged)

> The first break note in this repository. Its shape is the pattern every later
> note follows; the fields are fixed by
> [PROP-044 §4.7](../../spec/common/PROP-044-change-native-formats.md#machinery)
> — *what · epoch · who fixes · sunset · user recipe* — and this file is what
> they look like filled in. A note is not an apology and not a changelog entry:
> it is the artifact that makes a break **announced**, so that the gate can
> refuse an *unannounced* one.

## What changed on the wire

Every entry of `repomd.json::files` now carries a `kind` tag. Before:

```json
"by-name":       { "kind": "directory", "entries": 42 }
"primary.jsonl": { "size": 184522, "sha256": "sha256:…" }
```

After:

```json
"by-name":       { "kind": "directory", "entries": 42 }
"primary.jsonl": { "kind": "file", "size": 184522, "sha256": "sha256:…" }
```

Directory entries are **byte-identical** to before. Only `file` entries change,
and only by gaining one key.

## Why it is a break rather than an addition

The union was matched by *shape*, not by tag (`#[serde(untagged)]`). Under that
rule a `file` entry that lost a field did not fail — it was silently re-read as
whichever arm still fitted. That is the one failure class re-fetching cannot
cure, because the wrong answer looks like a right one and propagates into
derived state before anyone knows
([PROP-044 §2, law 1](../../spec/common/PROP-044-change-native-formats.md#laws)).
Tagging both arms converts that silent mis-read into a parse refusal.

A reader written against the old shape and given a new file will refuse the
`file` entries it now cannot recognise. That refusal is the point: it announces
itself.

## Why no epoch

An epoch mints a parallel world and costs a support window. This change does
not need one: **there are zero external consumers of the catalog today** (the
owner's standing knowledge, recorded as the campaign's baseline), so nothing
downstream can be stranded, and the system is in the pre-publication regime —
`public = false`, migrations do not run, and the standing user recipe is
*regenerate* ([PROP-044 §7](../../spec/common/PROP-044-change-native-formats.md#obligations)).
Epoch boundaries are for breaks that must run two worlds side by side; this one
runs one world and rebuilds it.

## Who fixes it

Nobody downstream. The index operator regenerates; no package author, no
consumer, and no third-party tool has an action.

## Sunset

None. There is no old world to retire — the previous shape is not published in
parallel and is not supported after this change.

## User recipe

```sh
vibe-index reindex --full --data-dir <path>
```

Any full rebuild rewrites `repomd.json` in the new shape. A catalog that is not
rebuilt keeps working with the matching binary; mixing an old binary with a new
catalog is the announced refusal above, not a silent misread.

## Notes for the next note

Written while `public = false`, where a break note is **optional** by D13 — the
regime reports breaks rather than demanding notes. It is written anyway,
because the first instance of a form is what every later instance copies, and a
form first met under pressure is a form invented badly. When the owner flips
`public = true`, notes stop being optional and this file is the template.
