**Делегирование — по умолчанию.** `SUBAGENT-MODE.toml` = `claudez`
(подтверждено владельцем 2026-08-14). Пакеты режет босс; воркеры не запускают
git; диффы читает, правит и коммитит босс; ревью не делегируется никогда.
Проверенная чистой форма фан-аута: **один cargo-тяжёлый пакет один на своей
линии, текстовые — на второй**. Что доказано работающим: периметр записи как
ЗАКРЫТЫЙ СПИСОК файлов; заголовки результата вшиты в пакет дословно; на каждое
утверждение базовой линии — confirm-or-refute с цитатой.

**Что пакет обязан нести, иначе поймает панель — а не воркер** (оплачено
шестью дефектами прошлой сессии, полностью в §8):

- **правило, а не координату** («по алфавиту», а не «между X и Y» — координата
  устаревает, правило нет; давать можно оба, но правило главнее);
- **`Cargo.lock` в периметре**, если пакет трогает зависимость;
- **`specmark::scope!` для каждого НОВОГО `.rs`** — это требование, и оно НЕ
  часть запрета на `#[spec]`/`#[verifies]`; пакет, слипший их в один пункт,
  теряет требование;
- **стоячие запреты проекта дословно** (`unwrap`/`expect` в доменной логике) —
  weak writer следует вшитому тексту и скользит по ссылкам;
- **требование цитировать ВСЕ строки `test result`**, а не последнюю: у крейта
  может быть две тестовые цели, и частичная цитата читается как «тестов нет».

**И одно правило верификации, которое дороже всех остальных.** Фикстура,
построенная упражнять расхождение, обязана быть доказана против **сохраняемого**
поведения, а не против правки, — иначе она удостоверяет ровно ту регрессию,
ради поимки которой заведена. «Заморозить только новое значение» — это та самая
точка, где гарантия замороженности теряет сторожа. И **счётчики предупреждений
панели читай как доказательство, а не как шум**: прошлую регрессию поймал не
golden, а `vibe check`, ушедший с 0 на 7 предупреждений.

**Два ожидаемых числа — НЕ дефекты, не чинить:** `vibe check` даёт **44 info**
`manifest_epoch` (до-эпоховые манифесты, помечаются намеренно) и **1 warning**
`local_source_freshness` по `addressable-specs` (следствие S3 при намеренно не
запущенном `vibe install`). Рост любого из них — находка.

**Слайс, трогающий `crates/vibe-wire/src/generated/**`, садится в порядке
стейдж → панель → коммит:** `check-codegen` это `git diff --exit-code`, то есть
рабочее дерево против ИНДЕКСА, и untracked-файлов он не видит.

**Судейство:** новый/правленый спек-файл судится тем же заходом:
scan → **mirror** → batch JSON → `merge-verdicts.py` → `seal` → долг 0. Мержу
обязан предшествовать `progress mirror`, иначе долг не проявится. Печать —
только за проверенное: `seal` ручается за ВСЕ вердикты файла, поэтому файл со
стоячим stale не печатать, пока не проверен каждый двинувшийся факт
(`tasks/text-stability.py` называет их поимённо). `campaigns/**` и `spec/WAL.md`
в судимый корпус не входят.

**Shell** (оплачено ошибками, не повторяй): никогда голый `cd` — только
`( cd … && … )` / `git -C` / абсолютный путь, иначе следующие команды молча
