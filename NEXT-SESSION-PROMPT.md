проблемы, суть решения, суть рекомендации; технические подробности —
отдельным блоком после. Номера разделов и якорей спек в чат не приводить.

делает то-то». Сложное — деревом.

## Шаг 2. Порядок исполнения

Слайсы ТЗ §3, строго по порядку: С0 → С1 → … → С10. Внутри слайса —
посадки размером в атомарный коммит. **Граница каждой посадки**
(`##WAL-C-LANDING-ORDER`): дифф → `cargo fmt --all` → `cargo xtask
specmap` (если трогались spec/код) → стейдж → полная панель
`bash tools/self-check.sh` (реальный код выхода: `; echo "EXIT=$?"`,
вердикт из хвоста, панель обрывается на первом красном — зелёный хвост
единственное доказательство) → суд тем же заходом (если трогался судимый
корпус: scan → mirror → батч в scratchpad → merge-verdicts → **scan ещё
раз** → долг 0) → коммиты по смыслу → `cargo xtask mirror` → обновить
`_STATUS:` в ТЗ, галочки `TASKS.md`, строку LOG ТЗ §9.

Судимый корпус: `campaigns/**`, `BACKLOG.md`, `TASKS.md`, `vibevm/vibespecs/WAL.xml` —
НЕ входят; `vibevm/vibespecs/boot/90-user.xml` — ВХОДИТ. Вердикт —
`confirmed | drift | unverifiable`, доказательства непустые и
нетривиальные.

Доклады в чат — статусы, не вопросы: «слайс N сел, панель зелёная, иду в
N+1». После каждого хода продолжай инструментами — цель проверяется после
каждого хода, и ход без инструментов глушит петлю.

## Шаг 3. Живучесть при компактификации

После каждой компактификации хук вбросит порядок перечитывания и живой
`git status`. Закон: **сводка компактификации имеет авторитет WAL —
последний в иерархии**. «Что сделано» выводится из `git log`,
`_STATUS:` ТЗ и `TASKS.md`, никогда из сводки. Компактификация посреди
посадки: незакоммиченный дифф сам есть состояние — прочитать
`git status`/`git diff HEAD`, достроить или осознанно откатить (никогда
не откатывать не читая). Если после сжатия неясно стоячее правило —
перечитать boot-лейн по `CLAUDE.md`; если неясно место в работе —
`_STATUS:` + `TASKS.md` + последние коммиты. Проверить живых воркеров
(`git worktree list`, фоновые задачи) прежде, чем плодить новых.

## Оплаченные ловушки — продолжают действовать

- **Пустой ИЛИ ОБРЕЗАННЫЙ вывод есть утверждение.** Скорми инструменту
  случай, который он ОБЯЗАН различить, прежде чем читать ноль
  доказательством. `ls | grep | head -5` уже стоил четырёх уехавших
  фактов.
- **Счёт бывает свойством инструмента.** Всякое число, на котором стоит
  решение, меряют двумя способами.
- **Панель, запущенная до правки, не про то дерево** — снять и
  перезапустить.
- **Каждая посадка делает ложными статусы предыдущей** («не построено»,
  счёт в прозе) — искать их специально, подстрока имени не найдёт.
- **Запись решения находит дефекты, которых не находит поиск** — сверять
  написанную спеку с исполняющим её кодом до стройки.
- **Мерить, что уже построено, до того как строить** — слайсы С2.4, С3.6,
  С5.1, С9.1 начинаются замером не случайно.
- **`cargo test` останавливается на первом упавшем ТАРГЕТЕ**
  (`--no-fail-fast`); **`cargo fmt` без `--check` выходит нулём и на
  грязном результате**; **красный СУЩЕСТВУЮЩИЙ тест при аддитивной правке
  — дефект правки**.
- **Страж доказывается КРАСНЫМ прогоном** — обезвреживание охраняемого
  роняет ровно свой тест.
- **`cargo xtask codegen` НЕЛЬЗЯ пропускать через `head`** (SIGPIPE
  уничтожает 22 сгенерированных файла; лечение
  `git restore crates/vibe-wire/src/generated/`; B-093).
- **`mirror --check` читать по строкам, не по хвосту** (B-090: «BEHIND
  хост» + «all targets in sync» + код 0 одновременно).
- **GitVerse отвечает через раз** — повторить; отказ одного хоста НЕ
  расхождение.
- **Shell:** никогда голый `cd` (ремонт: `cd <абсолютный корень>` с `pwd`
  и веткой в ТОЙ ЖЕ команде; дальше `git -C`/сабшелл); `cmd | tail;
  echo $?` печатает код ПАЙПА; правки только editor-инструментами
  (PowerShell 5.1 портит UTF-8 no-BOM); python — с
  `PYTHONIOENCODING=utf-8` и виндовым путём; коммиты heredoc
  `git commit -F - <<'MSG'`; никогда `git add -A` — явные пути.
- **Якорь с вердиктом не заменяют** — надгробие с наследником; сверка
  дифом множеств якорей против HEAD перед посадкой правки спеки.
- **Архив логов воркеров — ВНЕ чекаута:** `C:\Users\olegc\git\v\cache\agents\`.
