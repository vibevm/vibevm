## Порядок посадки

первом упавшем ТАРГЕТЕ** (`--no-fail-fast`); **`cargo fmt` без `--check`
выходит с нулём и когда результат не чист**; **красный СУЩЕСТВУЮЩИЙ тест при
аддитивной правке есть дефект правки, а не повод править тест** — новый сторож
строит СВОЮ фикстуру.

## Shell — оплачено ошибками, не повторяй

Никогда голый `cd` — **и опасен не он сам, а КАЖДАЯ команда после него**.
Ремонт — `cd <абсолютный корень>` с `pwd` и `git rev-parse --abbrev-ref HEAD` в
ТОЙ ЖЕ команде. Дальше: `( cd … && … )` / `git -C` / абсолютный путь;
`cmd | tail; echo $?` печатает код ПАЙПА — редирект в файл и `$?` сразу;
**правки только editor-инструментами**; python — с `PYTHONIOENCODING=utf-8`
**и ВИНДОВЫМ путём** (`C:\...`; путь вида `/c/...` из Git Bash он не видит —
поймано на боссе прошлой сессией); файл, вырезанный текстом, начинается с шапки
`//!`. **`git worktree remove` — по одному; если сорвалось, оставить каталог И
