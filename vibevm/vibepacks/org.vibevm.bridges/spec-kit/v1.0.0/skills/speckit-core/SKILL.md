# Spec Kit core bridge

Use this skill when the user wants the Spec Kit sequence for constitution,
specification, planning, task decomposition, or implementation.

The canonical command material is projected under
`references/upstream-commands/` from the exact upstream commit recorded by the
owning Vibe package. Read only the command reference needed for the current
phase. Preserve its phase order and stop conditions, while adapting invocation
syntax to the active agent rather than assuming one particular slash-command
host.

Do not edit, publish, or claim ownership of the upstream repository. Do not
treat this UPL adapter as relicensing its MIT-licensed reference material.
