Addresses

01A page address ends with a slash and the projections lie beside it as files: …/<document>/, …/<document>.md, …/<document>.xml.

The language segment

02The language is the segment after /doc/, and the source language carries no segment at all. A translation is served under the source package's coordinate, which is what lets one address become another by changing one segment.

island

03A page's content as finished HTML, rendered by the pipeline and inserted whole: the shell parses nothing of it. See the language segment.

resolver

04The one address that knows what a mount carries, asked with a spec:// citation and answering with the page it names.
