# Commit messages

How every commit in my repositories is written.

- Conventional Commits: `type(scope): summary`. The types I use are `feat`,
  `fix`, `docs`, `refactor`, `test` and `chore`.
- The summary is imperative and under 72 characters: "add the division
  guard", never "added" or "adds".
- One change per commit. A summary that needs the word "and" is two commits.
- The body says why. The diff already says what.
- No trailers, and no credit lines.
