# Writing style

For documentation, commit bodies and review comments alike.

- Short sentences. One idea in each.
- Cut the filler: "basically", "simply", "just", "in order to", "it should
  be noted that".
- Active voice, present tense.
- Name the thing: "the parser rejects `2 ^ 3`", not "invalid input is
  handled".
- British or American spelling, but one of the two per document.
