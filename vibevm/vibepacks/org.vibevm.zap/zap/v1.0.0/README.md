# Zap application bridge

This package contains only the Vibe application source proxy for Zap. The
application declaration, installer, source dependencies, and release index
locator are read from the resolved external Zap repository.

## Upstream

Source: <https://github.com/vibevm/zap>

The mutable application line is `refs/heads/1.0.0`. Each operation records the
exact resolved commit and portable source-tree digest before installation.
