## Decision and useful outcome

Proceed with two joined responsibilities, sharing A1 classification and captured bytes. A2 gives users a navigable ordinary Markdown document and stable authored names for exact sections, without turning `@fact`, `@requires`, `#use`, XML-looking text or heading annotations into rules. A3 makes original raw XML/binary resources survive install and format conversion, while selected Vibe documents retain working installed boot reads. Same-stem raw resources must coexist; only actual output or semantic-address collisions refuse.

A3 needs A2's ordinary-versus-native result/identity boundary, not completion of all export navigation. A2's pure parser/export join can progress separately from A3's materializer/installed-reader join once that interface is frozen. Neither task requires importing M16 document server, resource-query transport, universal world snapshots or permissions frameworks. Conversely, A3 cannot close with a pure XML inspector: its original acceptance explicitly says install/derive/read round-trips, and its saved notes explicitly require actual selected boot renderer integration.

## Main owners to retain

- `vibe-spec::source_policy`: selected-root policy observation, held reads and detached checkpoints. Export-only input must pass the same central explicit-policy predicate. Keep caller-root aliases distinct from no-follow installed descendants.
- `vibe-safefs::SourceObservation` via A1 helper: original bytes + same-held permissions/identity, hardlink-compatible finite source observation. No imported state-reader single-link ban, probe/reopen or arbitrary source quotas.
- `vibe-specdoc`: pure Vibe pivot, `from_markdown` through progress-core and `from_xml_with` through quick-xml; no manifest/FS discovery. Existing load::SourceKind distinguishes projection-relative diagnostics. Native source-map offsets are not ordinary tree offsets.

## Prototype quality: keep the useful parts, reject the accidental architecture

1. **CommonMark structure is substantive.** `pulldown-cmark = "=0.13.4"`, options empty plus tables, `into_offset_iter`: headings (including setext), fences, links, text/code; exact heading/section spans; normalized visible heading text; deterministic per-snapshot IDs. Tests cover nested fence opacity, UTF8 spans, duplicate titles and inert words. It is a selected outline, not a full HTML/Markdown AST: ignored list/quote containers and image events deserve explicit tests/documentation before claiming general structural fidelity. Headings inside lists/quotes and image labels are unexecuted discriminators, not observed failures. Public node(id) indexes unchecked and IDs can be passed from another parsed document; target should offer checked access/document-scoped results instead of implying cross-snapshot validity.

2. **Export grammar and join are real.** ASCII package-unique name, exact portable file, nonempty normalized heading path; facts join checks declared row, selected CommonMark media, resource/declaration provenance and witness against the parsed snapshot. Sibling ambiguity refuses. But specdoc repeats the name grammar and hashes raw source separately although core/facts already own these. Target pure selector should resolve headings only; durable export name/witness binding belongs to host join. Later `canonical_export_resource` merely constructs identity and is not a reader. A2 does not need a new public URI transport to deliver its explicitly required library consumer.

3. **XML raw preservation is good; outline claims must be honest.** xml_data retains exact bytes on invalid/nonUTF8/unsupported encoding/DTD/reference/limit errors and never uses a resolving API. It counts root/elements/depth/text/comments, not a navigable tree and not complete XML validation. Its custom name/declaration/PI handling has no broad conformance proof. Do not advertise counts as a complete XML tree or validating parser. Root/count/depth is a legitimate bounded optional inspection capability under the original criteria, which do not demand a DOM or XML navigation. Recommend retaining that explicitly named summary initially; add node navigation only for a concrete consumer need. All structural diagnostics leave raw accessible. Runtime parser-specific malformed-name/declaration/reference discriminators still need tests.

4. **Historical fixed caps are policy, not fundamentals.** Prototype uses XML inspection4MiB/depth64/elements10000/text1MiB, manifest1MiB, source16MiB, map output64MiB/aggregate256MiB/4096rows. A1 target deliberately has no fixed global source quota. Optional inspection may take an explicit work-limit policy and return Unavailable(Limit), but cannot hide/refuse raw solely because it exceeded structural budget. Do not import those constants into source admission/map authority without root decision.

5. **Derived selection is useful but cannot be copied whole.** It re-parses raw TOML key presence, probes/reopens manifests, uses state snapshots and ad hoc lowercase aliases. Main already has typed presence, held hardlink-safe sources and portable path_identity_key. Prototype transform includes later CopiedUnconverted diagnostics/replay work and structured conversion failure vocabulary: not an A3 prerequisite. Reuse main converter; ordinary data never invokes it. Do not silently copy an unrelated converter recipe bump.

6. **Installed mapping is the right direction, weaker guarantees need repair.** It binds independent package hash/version/format, manifest row, record and output hashes; maps only selected Vibe to native addresses. It explicitly cannot prove converted original-file SHA because record retains package hash + output digest. Main needs retained Project/Pinned descendants, no map validation followed by unsafe reopen, and actual media dispatch through both Simple and Normal readers. Prior audit flagged prototype Simple projection by filename suffix and pattern membership bypass; those are unacceptable regressions over A1/F05, not reasons to omit A3 reader integration.

7. **Later captured.rs is not an A2/A3 prerequisite.** Its spec edge/test module identifies M16 document analysis. It packages native projection and raw views for another consumer; do not import it or a fake future interface just because final prototype lib.rs registers it. Minimal ordinary result boundaries suffice.

## Proposed concrete API/format closure (review before activation)

Names below are proposed new APIs, not claims they already exist.

**A2 neutral grammar owner:** `vibe-specdoc::commonmark::CommonMarkDoc::parse(&str) -> CommonMarkDoc`; stores exact original UTF8 source; `source()`, `nodes()`, checked `node(NodeId)->Option<&Node>`, `resolve_headings(&[String])->Result<SectionSelection,HeadingSelectionError>`. `SectionSelection { node, span: Range<usize> }` belongs to this document; no durable identity, filesystem root or second hash. Headings/fences/links come only from one standard CommonMark event parser. Recommend reviewed exact pulldown-cmark0.13.4 adapter, matching inspected prototype API, since main has no ordinary grammar dependency. Not a second equivalent Vibe parser: existing native scanners stay their only grammar owner. Add dependency only after root review, with pinned-version offline availability resolved by implementation owner; no acquisition performed in this audit.

**A2 core manifest:** `SourceExport { name,file,headings }` with strict serde/new validation and private fields; `PackageMeta.source_exports: Option<Vec<SourceExport>>` retains key presence, including []. One package explicit-policy predicate = sources.is_some() OR source_exports.is_some(); update A1 helper/installer/facts decisions through that owner, never Vec-empty or raw-TOML fallback. Valid export-only metadata grants zero selected sources and resolver returns UnselectedSource; it must not revive legacy. Reject duplicate names and explicit null; absent serialization remains unchanged. A different choice to reject export-only metadata entirely is possible but must be explicit; recommendation preserves diagnostic export resolution without guessing interpretation.

**A2 actual host join:** extend DeclaredDocumentObservation with structure retaining original bytes and CommonMarkDoc; add `resolve_declared_export(package:&PackageMeta,name:&str,observation:&DeclaredDocumentObservation)->Result<DeclaredExportResolution,DeclaredExportError>`. Return package/export/resource identity, snapshot selection and existing SourceFileWitness; validate export against current descriptor and same raw observation. No FS read/reparse and no Fact authority. A selected installed Mixed read through existing captured-source path must call this resolver in integration tests, not only construct a SourceExport value. Facts adoption still sees zero facts for ordinary structure. Library reader completion is original A2 scope; GUI/CLI/MCP named-resource transport remains separate.

**A3 pure raw inspector:** `inspect_xml_data(raw:&[u8], limits:InspectionLimits)->PreservedData<'_>` and `preserve_opaque(raw:&[u8])->PreservedData<'_>`; raw always available, inspection is NotRequested / Available(XmlOutline) / Unavailable(XmlDataIssue). Use incumbent quick-xml0.41 events, no DTD/entity expansion/FS/network. UTF8-only structure is a truthful initial profile with original bytes retained for every other encoding. If outline includes nodes/spans, spans refer to original bytes including BOM offset; avoid pretending Vibe Markdown projection positions are original positions. No core/manifest dependency in pivot.

**A3 transformation kernel:** expose a private selected-bytes seam in existing derived owner, e.g. `prepare_declared_output(relative,descriptor,raw,format,overlay)->Result<PreparedOutput,...>`. Raw/CommonMark/XML-data/opaque/unclassified copy original bytes/path; selected native only uses existing pivot by declared media. Separate original resource identity, output path and canonical native address, compare collisions via incumbent portable path identity. Preserve exact generated exclusion, mode/copy/hardlink laws. All predictable selected-source/conflict/output decisions precede hooks/metadata. Later source races remain ordinary finite-observation partial failure, not transaction claims.

**A3 installed read:** new bounded workspace `read_descriptor_outputs_in(project:&Project,slot:&Pinned,expected:SelectedSlotExpectation)->Result<Option<DeclaredOutputMap>,...>`, using captured slot record parser, held manifest policy and selected independent kind/group/name/version/hash/target format. Map output→original source/interpretation/materialized media/output digest; only selected native rows get semantic addresses. Use supplied held bytes/read capability to extend incumbent resolver source location; do not grant authority by canonicalizing slot pathname. Missing selected hash, record/manifest mismatch, changed output, raw-as-native or representation ambiguity refuse. No new record wire field needed just to join existing witnesses; original-file authentication remains absent.

A3 bootstrap carriers: `install/bootgen/hybrid_emit.rs`, native_managed.rs, analyze.rs, replay_prepare.rs and actual boot_artifacts input/render owner thread the expectation from ResolvedDep/independent lock. Test real emit_package_units, not only a manually injected map. Public standalone legacy render keeps its route until it has independent binding; unsupported declared entrypoints retain precise guards. This closes first installed reader without claiming A4 skill/citation/query completion.
