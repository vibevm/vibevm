# Truthful source selection through the incumbent reader

Root decision2026-11-04, following compiled current-source probes at0e98486da (10tests:6controls/characterizations,4intended invariant failures;21observations). This is implementation design, not acceptance. Reuse the accepted F01 lexical boundary and F03 held shared-source observation; source descriptors/proofs/exports and portable sibling-alias policy remain separate obligations.

## Requested anchor ambiguity

A requested Markdown path must select one node. The first segment is the existing global anchor search and must be unique there. Each later segment must be unique among the current node's direct children. Missing and ambiguous are different diagnostics. Do not reject every read merely because some other anchor repeats. Qualified left.leaf/right.leaf remain valid when left/right are individually unique and each has one leaf. Empty path still denotes the whole document. Preserve the existing qualified-heir hints for a missing short anchor. XML's whole-document duplicate-ID validation stays intact; the failed initial cross-format control was a probe mistake, not a product defect.

Keep parsing and path selection in DocTree. An additive checked selection API or a focused internal helper is acceptable; do not change the existing documented first-occurrence low-level lookup everywhere without reviewing its other callers. Filesystem-backed source/embedding/prompt address selection must use the checked path, not another parser or another source read. Use meaningful source-level diagnostics including requested path and source, not generic not-found for ambiguity.

## Pattern authority and membership

A pattern's group is a fixed coordinate namespace; only the package name has wildcard syntax. Emit addresses in that actual group. This deliberately replaces the stale group-blind/lexical-survivor rule: its premise that slots lack groups is no longer true, and actual point resolution is now group-qualified. Tests proved foreign-group false positives and another group's file controlling membership. Do not import prototype's blanket same-name-across-groups ambiguity refusal: unrelated groups are distinct coordinates. Matching group/name semantics must agree with point resolution.

A resolver with_selected_world enumerates only its selected dependency map and uses those exact roots/versions. It does not inspect unrelated installed slots, and unselected disk changes cannot add/remove members. Self-coordinate priority and direct self lookup remain unchanged; patterns enumerate the applicable dependency world rather than manufacturing another self installation. A matching selected coordinate whose explicitly requested pin disagrees returns the existing selected-version mismatch, not an omitted pin or an alternate installed candidate.

Without a selected map, enumerate the requested group's materialized slots using the existing admitted root/held no-follow directory facilities. Absent dependency layout, no matching name, a genuine empty version set and an actual missing requested document/version produce nonmembership/empty set. An existing matching slot that is a regular file, a symlink or an unreadable/unsafe object refuses as a source observation; it is not an absent package. Nonmatching names/groups do not become candidate source reads. Keep the current ordinary-file layout fallback and explicit-root alias semantics. No new ambient scan is added to selected-world mode.

An explicit @version is preserved and honored in each emitted concrete address and membership check, including non-newest versions. Nonexistent explicit versions in the ordinary installed-set mode are absent members; never substitute newest. Without an explicit pin, retain the ordinary freshest-installed rule and existing versionless address spelling; selected-world mode retains the exact selection supplied by its caller. This does not promise a whole-pattern snapshot across arbitrary subsequent filesystem changes. Preserve any revision token as address data; this task does not implement new revision-proof semantics.

After candidate selection, document membership uses the same point-lookup owner, including safe path validation, layout and ambiguity. Preserve active-format context wherever the caller already supplies it; the existing formatless pattern API retains its md/xml vocabulary rather than guessing custom suffixes from disk. Only genuine absence is nonmembership. PairCollision, ambiguous PROP/FEAT stem, non-directory parent, unsafe or unreadable source errors must propagate; no is_ok/filter_map/read_dir flattening that erases them. Reuse/refactor current observed-root/layout/version helpers instead of reintroducing pathname-only authority or canonicalizing derived descendants as new roots. A mutable filesystem is observed finitely; no authenticated-source, hostile-ABA or whole-closure atomicity claim is added.
