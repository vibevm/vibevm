# First explicitly supplied public boolean for ordinary packages

Implement a required, nonsecret, explicitly supplied bool with no default on the already admitted ordinary local-registry route. Preserve false versus omission throughout normalization, consumer reconciliation and historical replay. Omission must identify consumer and missing required parameter; a wrong type must refuse as invalid rather than supplying a default. If several actual consumers target a shared instance, require an explicit answer from each, merge identical values and refuse disagreements before effects. Never include private values in an error. Do not admit optional defaults, paths, secret parameters, profiles with parameter answers or forwarding by removing the general guard.

Prefer deriving the validated typed result from the existing lock's original per-consumer parameter map and retained definition. Keep the parameter and selected config-value namespaces distinct: do not silently overwrite an identically named value or imply a dependency effect. Expose effective public parameters as an independently identified typed projection through the existing inspection owner. Document the public representation before changing it; retain previous output when no parameters are selected. No injection into hooks, process argv/environment or new global storage. No new lock epoch unless old-reader and old-install-writer compatibility cannot be preserved and separately accepted.

Gate with public install and read-only inspection for true and false; missing required, wrong type and conflicting consumers refuse without lock, slot or hook mutation. Confirm original intent survives a fresh-process install and inspection without rewriting accepted state. Test the prior released-in-this-campaign binary as reader and writer against the new record in isolated settings. A changed parameter meaning must not be silently accepted by ordinary update. Record compatible source and binary identities, terminal outcomes and untested cases. No USER-PROJECT, AR or IDE changes.
