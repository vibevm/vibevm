The PATH proxy decodes the entire strict generated index3 or index4 before extracting the unchanged routing fields. It retains default/session selection, argument forwarding and index bytes; it adds no app-domain dependency or read-time migration. Its existing probe protocol remains /2.

This forward reader is a prerequisite, not proof that previously installed copies have been upgraded. Root's follow-up source audit found that the mixed-index test uses the new binary for both installations; existing session copies can remain old, and global synchronization follows index publication. Runtime writer activation is held for an actual old-copy upgrade guarantee and discriminating failure/session tests. That follow-through does not require delaying the additive reader itself.
