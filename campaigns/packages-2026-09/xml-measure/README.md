# XML measure harness

Одноразовый внешний полигон для измерения холодного boot-recall по трём материализациям. Все создаваемые проекты и результаты живут вне репозитория, по умолчанию в `/c/Users/olegc/git/v/vibevm-xmlmeasure`.

## Порядок запуска

1. В основном checkout соберите актуальный `vibe`: `cargo build --release -p vibe-cli`.
2. Из этой директории выполните `bash setup.sh`. Скрипт пересоздаст внешний полигон, соберёт локальный registry, установит три варианта и проверит их INDEX.
3. Выполните `bash enum-tiers.sh`, чтобы записать доступность простых Codex-tier моделей в `runs/tiers.txt`.
4. Запускайте матрицу через `bash run-probe.sh --lane codex --model <model> --effort low --variant <xml|markdown|mixed>`. Сначала проходят простые обслуживаемые модели, последней — `gpt-5.6-sol`; каждый model-tier прогоняется по всем трём вариантам.
5. Отдельно прогоните GLM big по всем вариантам: `bash run-probe.sh --lane claudez --variant <xml|markdown|mixed>`.
6. Выполните `bash score.sh`. Машиночитаемый результат появится в `runs/scores.csv`, сгруппированная таблица — в `runs/summary.txt`.

Промпт обязан оставаться format-blind: нельзя называть формат, расширения или подсказывать различия материализаций. Не исправляйте транскрипты вручную. Итоговые числа и наблюдения переносятся в `spec/common/PROP-045-xml-spec-sources.md` §5a отдельной боссовой правкой после ревью измерения.
