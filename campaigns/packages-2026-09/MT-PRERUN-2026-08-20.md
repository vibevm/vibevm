## Deviations

1. **`vibe tree --quiet` не quiet.** Help: `Reduce output to a single summary
   line`; наблюдение: 51 строка полного plain tree, exit 0.
2. **Non-TUI `vibe prefs` запускается с пустой schema.** На чистом temp `list`
   возвращает 0 keys, `get vibe.tree.palette` не видит built-in default, а
   `check` считает TUI's own declared key неизвестным после успешного `set`.
   Из читаемого source видно точную границу: `prefs ui` строит schema из
   `TreeSettings`, а shared CLI loader оставляет `Schema::new()`.
3. **Origins surface расходится с contract.** Contract-форма
   `vibe prefs --show-origins` rejected с exit 2; binary предоставляет
   `vibe prefs show-origins [key]`.
4. **Shipped help несёт stale phase-lore.** `vibe prefs set --help` говорит
   `basic write; phase 2.7 enriches with diff-from-default + comment-preserve`,
   тогда как source этой команды уже описывает и вызывает enriched persistence.
