## Цель — два атома, два коммита

**A2.25** `vibe doc check --style` в `vibe-doc`: запрещённые слова и
обороты по языку страницы (списки из пакета, без учёта регистра, по
границам слов; фразы — как последовательности слов); длина фраз по виду
блока (X-028: шаги списка и `note` предупреждения — 20 слов ошибка, `p` в
процедурах — 25 ошибка, коридоры — 35 предупреждение); абзац длиннее 6
фраз — предупреждение; термин глоссария, чьё первое вхождение на странице
— не ссылка на якорь глоссария и не глосса в той же фразе — ошибка (обычные
слова из оговорки PROP-057 не считаются); больше двух терминов в фразе —
предупреждение; отсылки без объяснения — ошибка; заголовки Overview,
Summary, Conclusion, Next steps, Key takeaways — ошибка (страница вопросов
с заголовками-вопросами — не ошибка); `!`, эмодзи, больше одного тире на
абзац, жирный в прозе — ошибка; `prompt` на странице сценария без
ассертов — ошибка; индекс читаемости — в отчёт. `--style` входит в
`--min 100`. Фикстуры: «плохая» и «хорошая» страницы из §9, русская
фикстура из §10. Прогон по руководству: числа в отчёт; **страницы не
править** — находки идут в `AUTHOR-QUEUE.md`-подобный список в отчёте.
Коммит: `feat(doc): lint documentation prose against the style law`.

**A2.29** `vibe doc check --prompts`: конфигурация `[doc.prompts]` в
пакете (`runner` — команда, которой передаются текст промпта и рабочий
каталог; `timeout`; `sample`); для каждого `prompt` с ассертами — чистая
песочница с фикстурой (`fixture` как у `example`), установленный скилл по
`needs`, запуск раннера, затем ассерты по порядку с нормализацией A2.9;
отчёт: промпт, ассерт, код выхода, хвост вывода агента; `--sample N` с
фиксированным зерном. **Не в панели.** Первый раннер — команда, которую
задаёт конфигурация; в этом пакете реализуй механику и фикстуру с
фальшивым раннером (скрипт, который делает ровно то, что нужно для одного
промпта), настоящий агентский прогон — отдельным запуском центральной
сессии. Линтер получает правило «промпт без ассертов — ошибка». Коммит:
`feat(doc): run documented prompts through an agent and assert the outcome`.

вызывать.

## Диск и каталог сборки

ноль во время фазы. В конце работы **удали** свой приватный каталог
сборки и проверь `df -h` до и после; при нехватке места гейты падают
ошибками линковки (`link.exe … 1108/1140/1201`), не имеющими отношения к
правкам — повтори после освобождения места, а не ищи причину в коде.
