## Сделать — шесть замечаний, шесть атомарных коммитов

**A. Кнопка копирования у строк установки на главной (`/` и `/ru/`).** Рядом с каждой командой
(`curl … | bash`, `irm … | iex`) — кнопка-пиктограмма (инлайновый SVG в дизайн-системе, без внешних
ресурсов, R-09), `aria-label` из `i18n.ts` («Copy» / «Скопировать»), по нажатию — `navigator.clipboard.writeText`
ровно текста команды и короткое подтверждение («Copied» / «Скопировано», ~1.5 с). Обработчик — Qwik
`onClick$` (не инлайновый `<script>`: CSP считает хэши инлайновых скриптов, не добавляй ни одного). Если
clipboard API недоступен — кнопка не показывается. Обе темы, 1440 и 390 px.
Коммит: `feat(web): copy an install line from the landing with one click`.

**B. Переключатель темы в правом верхнем углу главной; тема по умолчанию — тёмная.** Тот же переключатель,
что на страницах документации (если его там нет как компонента — вынести в `design/src/components`, чтобы
был один); на лендинге — в шапке справа. Умолчание `dark`: в `site/src/config.ts` (`defaultTheme` без
конфигурации = `dark`), в `docker/site.toml` (`default_theme = "dark"`), в `site.example.toml` (текст про
умолчание). Выбор читателя, сохранённый в хранилище, по-прежнему сильнее умолчания (это держит существующий
тест `theme-init`). Обнови тесты, которые пинят «system».
Коммит: `feat(web): put the theme switch on the landing and default to dark`.

**C. Поиск в правом верхнем углу не работает.** Разбери, что он делает сейчас (форма? куда ведёт?) и сделай
рабочим на статическом сайте: клиентский поиск по данным, которые сборка уже кладёт рядом (манифесты
библиотеки: названия документаций и страниц, аннотации, координаты), с выпадающим списком результатов
(ссылки на страницы), клавиатурой (стрелки, Enter, Esc), без внешних ресурсов и без нового инлайнового
скрипта. Индекс строится сборкой в один JSON рядом с `manifest.json` (`tools/build.mjs`), грузится лениво
при первом вводе. На лендинге и на страницах документации — один и тот же виджет. Если сегодняшняя форма
ведёт на несуществующий маршрут — это и есть причина, опиши её в отчёте.
Коммит: `fix(web): make the header search find pages`.

**D. Иконка карточки — на уровне названия (десктоп).** В `Card` дизайн-системы: от 768 px глиф стоит в одной
строке с заголовком (по базовой линии/центру), ниже — как было (сверху слева). Ничего не менять в
данных карточек.
Коммит: `fix(web): align the card glyph with its title on wide screens`.

**E. Карточки страниц показывают аннотацию руководства вместо своей.** В `routes/doc/[...path]/index.tsx`

**F. Элементы управления чтением внизу страницы перекрывают поиск и выбор языка.** Воспроизведи: долистать
