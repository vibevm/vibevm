# PACKET-P4-O8 — сайт из многих библиотек: по одной на исходную документацию, все издания реестра в одной сборке

##subagent-quiet-clause

Ты — воркер кампании документации, исполнитель уровня `opus5`. Boot-лейн
репозитория не читать. Твоя инструкция — этот файл и ровно те файлы,
которые он называет. Предусловия: в ветке P4-O6 (`957e578a`, `630f9d09`)
и P5-O1 (`a6c71db7`…`97c9a57e`, `4b86c464`); проверь `git log --oneline -40`.

## Почему пакет существует

Реестровый билдер `vibe doc build-site` (P5-O1) рендерит **48 изданий**
реестра и хоста в деревья `<out>/.vibe-site/trees/<координата>/{html,md,xml}`
и зовёт `node tools/build.mjs static` с `VIBE_DOC_OUT` = все деревья.
Сборка сайта падает:

```
Error: 2 source manifests in one library (org.vibevm.core/vibevm,
org.vibevm.core/vibevm-docs): this build renders one documentation and
the adaptations of it
    at editionsOf (site/src/seo/editions.ts:114)
```

`editionsOf` строит **одну** библиотеку — один источник плюс его
адаптации. Для фазы 4 это было верно (одно руководство и его переводы);
для сайта реестра библиотек столько, сколько исходных документаций.
Отчёт: `findings/WORKER-REPORT-P5-O1.md`, А-1 и «Контракт с web-пакетом».

## Цель — один атом, один коммит

**Библиотек столько, сколько исходных документаций.** `editionsOf`
группирует деревья по координате **источника** (адаптация — к своему
источнику по `translates`; источник без адаптаций — библиотека из одного
издания) и строит по библиотеке на группу; маршруты `/doc/**` рендерят
страницы **всех** библиотек по адресам `##SITE-MOUNT` в обоих написаниях
версии; дверь `/doc/` — полка библиотек (по записи на издание: заголовок,
издатель, звёздочка официальности **как её посчитал билдер** — R-23:
сайт ничего не пересчитывает и ничего не хранит, читает то, что несут
деревья и их манифесты), каталоги языков — по языкам, которые есть хоть у
одной библиотеки; `/doc/llms.txt`, `/doc/manifest.json`, `/doc/resolve.json`
и sitemap-индекс — по записи на издание всех библиотек; `lint-links`
и гейт числа страниц считают все библиотеки. Без `VIBE_DOC_OUT` —
фикстура, как сегодня (одна библиотека). Одна библиотека в деревьях —
поведение и байты, как до тебя (паритет P4-O6 по числам: 103 страницы
над руководством, 13 187 ссылок или их новое значение после P4-O7 —
назови). Коммит: `feat(web): build one library per source documentation`.

**Хвост (тем же коммитом или вторым, назови):** X-055 — `og:image` и
превью карточки берутся из `media.preview` манифеста (P4-O6 разбирает
поле), эвристика «единственный PNG 1200×630» остаётся запасным путём для
манифестов старше поля.

## Тесты

Node-тесты: две библиотеки в одной сборке (фикстурное дерево P4-O6 плюс
второе дерево — скопируй голден второго пакета конвейера или собери
`target/debug/vibe.exe doc build --format html` над `crates/vibe-doc`
фикстурой второго пакета и положи как фикстуру, назови источники);
адаптация приписывается своему источнику; источник без адаптаций;
дверь `/doc/` перечисляет обе. Playwright: дверь `/doc/` над двумя
библиотеками. Живой прогон: `target/debug/vibe.exe doc build-site
--config vibevm/vibepacks/org.vibevm.doc/web/v0.1.0/site.example.toml --out <scratch>`
(как в отчёте P5-O1 — состояние билдера уводится из `~/.vibe` через
`$VIBE_SETTINGS`, смотри там; сеть — чтение реестра) → сборка сайта над
всеми деревьями: число страниц, «island(s) from the documentation trees»,
`link(s) followed`, 0 broken, «in a form this site does not carry»,
`du -sh dist`; `node tools/parity.mjs` зелёный; `pnpm floor`; `pnpm
test:e2e`; `node tools/build.mjs embedded` — 14 страниц и короткая голова
как были.

## Что не трогать

Rust (`crates/**`, `xtask/**`, `schemas/**`); `site/src/generated/**`;
лендинг и `tools/parity.mjs` (паритет остаётся зелёным без новых правил);
PROP-файлы и вижен; ничего на сервере (R-24). В дереве параллельно
работает P4-O7 в `crates/vibe-doc/**` и `crates/vibe-doc-server/**` —
его файлы не трогать и не стейджить; общий `target/debug/vibe.exe` может
быть занят — ждать, **чужие процессы не останавливать** (J-105). Каждый
твой коммит оставляет web-пакет собираемым (сборка и пол — до коммита).
