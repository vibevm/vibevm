# A0.18 Переиспользование i18n

2026-09-11
Дерево: b1291b06

## Ответы

**Типы и функции, которые может переиспользовать `vibe-doc`.** Всё живёт в
`crates/vibe-core/src/manifest/i18n.rs` (модуль `vibe_core::manifest::i18n`,
спецификация PROP-003 §2.7):

- `pub const DEFAULT_CANONICAL_LANGUAGE: &str = "en"` (`i18n.rs:28`).
- `pub struct I18nDecl { canonical: String, available: Vec<String>, fallback:
  Vec<String>, preferred: Option<String> }` (`i18n.rs:49-73`) — уже
  встроена полем `pub i18n: I18nDecl` прямо в манифест
  (`crates/vibe-core/src/manifest/document.rs:241-242`), то есть чтение
  `[i18n]` из `vibe.toml` `vibe-doc` получает бесплатно через `vibe-core`,
  без своего парсера.
- `I18nDecl::project_preference_chain(&self) -> Vec<String>`
  (`i18n.rs:106-126`) — цепочка отката проекта: `preferred` →
  `available[0]` → `fallback` (без дублей) → `canonical` →
  `DEFAULT_CANONICAL_LANGUAGE`.
- `I18nDecl::is_default(&self) -> bool` (`i18n.rs:93-98`) — быстрая проверка
  "i18n не объявлен".
- `pub fn localised_path(path: &Path, lang: &str) -> PathBuf`
  (`i18n.rs:132-149`) — построение sidecar-имени (`README.md` + `"ru"` →
  `README.ru.md`).
- `pub fn resolve_localised(base_dir: &Path, logical: &Path, chain:
  &[String]) -> Option<PathBuf>` (`i18n.rs:158-182`) — обход цепочки: точный
  тег → тег без региона (`pt-BR` → `pt`) → канонический файл.
- Паттерн композиции CLI-оверрайда с `[i18n].preferred` проекта:
  `pub(crate) fn build_language_chain(language: Option<&str>, manifest:
  &Manifest) -> Vec<String>` (`crates/vibe-install/src/fetched.rs:74-85`) —
  клонирует `manifest.i18n`, при наличии `--language` перезаписывает
  `.preferred`, затем вызывает `.project_preference_chain()`. `vibe-doc`
  может воспроизвести ровно эту композицию, а не изобретать свою.
- Место хранения результата — поле `language_chain: Vec<String>` в
  `[meta]` лок-файла (`crates/vibe-core/src/manifest/lockfile.rs:128-133`,
  коммент прямо ссылается на `[i18n].project_preference_chain()`); если
  `vibe-doc` резолвит язык через обычный install-путь, отдельного поля в
  лок-файле заводить не нужно.

**Что в `[i18n]` не подходит doc-пакетам (устройство sidecar-раскладки
сейчас).** `[i18n].available` (уровень пакета) и §2.7.1 в
`vibevm/vibespecs/modules/vibe-resolver/PROP-003-dep-evolution.xml:384-428`
описывают перевод как файл **внутри того же пакета**, с `.<lang>` перед
расширением рядом с оригиналом (`README.md` → `README.ru.md`,
`10-flow-wal.xml` → `10-flow-wal.ru.md`). Наличие проверяет
`I18nCoverageCheck`
(`crates/vibe-check/src/checks/i18n_coverage.rs:14-33`): для пакета с
непустым `[i18n].available` он берёт логический путь из
`[boot_snippet].source` этого же пакета и требует существования
канонической формы (ошибка) плюс предупреждает об отсутствии формы для
каждого языка из `available` (warning) — то есть весь механизм закодирован
в терминах "файл рядом с файлом одного и того же пакета". По данности
задания перевод документационного пакета — самостоятельный пакет
`<имя-документации>-<lang>`, а не sidecar-файл; ни `I18nDecl` (нет поля
"какой пакет — чей перевод"), ни `I18nCoverageCheck` (смотрит файлы одного
пакета, не граф пакетов) такую связь не выражают — механизма "пакет X —
перевод пакета Y на язык L" в прочитанном коде нет.

**Предложение поправки к PROP-003 §2.7 (атом A1.6b), одно предложение.**
Добавить в §2.7.3 примечание: пакеты `kind = "doc"` переиспользуют
BCP-47-теги и цепочку предпочтения (`I18nDecl::project_preference_chain`,
§2.7.2–2.7.3) для выбора языка, но не участвуют в sidecar-раскладке §2.7.1 /
`[i18n].available` — перевод такого пакета оформлен отдельным пакетом
`<имя>-<lang>`, а связь этого пакета с оригиналом — открытый вопрос, пока не
описанный в §2.7.

## Свидетельства

```rust
pub fn project_preference_chain(&self) -> Vec<String> {
    let mut out: Vec<String> = Vec::new();
    if let Some(p) = &self.preferred {
        out.push(p.clone());
    } else if let Some(first) = self.available.first() {
        out.push(first.clone());
    }
    for f in &self.fallback {
        if !out.contains(f) { out.push(f.clone()); }
    }
    if !out.contains(&self.canonical) { out.push(self.canonical.clone()); }
    ...
}
```

Команда: `sed -n '74,85p' crates/vibe-install/src/fetched.rs`:
```rust
pub(crate) fn build_language_chain(language: Option<&str>, manifest: &Manifest) -> Vec<String> {
    let mut effective = manifest.i18n.clone();
    if let Some(lang) = language {
        effective.preferred = Some(lang.to_string());
    }
    if effective.is_default() && language.is_none() {
        Vec::new()
    } else {
        effective.project_preference_chain()
    }
}
```
