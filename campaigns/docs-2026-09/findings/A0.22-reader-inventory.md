### 3. Внешние зависимости скриптов ридера

Клиентские скрипты ридера — `public/js/theme.js`, `public/js/lang-fallback.js`, первые 60 строк `public/js/lightbox.js`, инлайн-скрипты «Paragraph anchors» и «Settings menu» в `article.html.tpl`, и design-system `ui.js` — **не имеют внешних зависимостей**: чистый vanilla JS (IIFE, `var`), ни одного `import`/`require`, ни одного тега `<script src="https://...">`. Используются только нативные API браузера: `document.cookie`, `localStorage`, `sessionStorage`, `IntersectionObserver`, `navigator.clipboard`, `history.replaceState`/`history.scrollRestoration`, `matchMedia` (последнее — в ui.js, для мега-меню).

Найдена одна ссылка на внешний домен — `https://gitverse.ru` (`podcast-episode.html.tpl:968`), но это обычная исходящая ссылка-бейдж в разметке, не скрипт и не библиотека; к вопросу зависимостей ридера не относится.

Отдельно отмечена билд-тайм (не клиентская) зависимость: `import readingTime from 'reading-time';` — npm-пакет, используется в `build-articles.mjs:23` (и аналогично в `build-podcast.mjs`, `build-papers.mjs`, `build-careers.mjs`) для расчёта времени чтения на этапе сборки Node.js. Это не рантайм-скрипт ридера и в Rust-сборке vibevm-docs не участвует — счётчик слов/минут (константы 200/250 подтверждены выше) там нужно реализовать самостоятельно.

## Расхождения с решениями

REVIEW: D-22 п.3 требует тему «тёмная/светлая/**системная**»; в коде только два состояния — `getTheme()` возвращает `'light'` либо `'dark'` (`theme.js:41-43`), cookie `theme` документирован как `"dark" | "light"` (`CLAUDE.md:486`). Авто-темы (`prefers-color-scheme`) в прочитанных файлах нет.

REVIEW: D-22 п.3 требует «значения в localStorage» для темы/шрифта/ширины колонки/якорей; в коде все четыре хранятся в **cookie**: `theme` (`theme.js:51`, `setCookie(name, value, days)` — 365 дней), `font-size` и `col-width` (`article.html.tpl:858,895`, `max-age=31536000`), `paragraph-anchors` (`article.html.tpl:798`, `max-age=31536000`). В localStorage на деле хранится только `reading-pos:<путь>` (фича 5, D-22 п.5) — тут совпадает.

## Открытые вопросы

- Сохранение URL-фрагмента (`#pNN`/`#id`) при переключении языка (фича 2): не обнаружено ни в билд-тайм генерации ссылки (`buildLangSwitch`, `build-articles.mjs:377-423`, статический `href` без хэша), ни в двух прочитанных инлайн-скриптах (Paragraph anchors, Settings menu) — патча `.lang-switch a` через `location.hash` там нет. Не установлено, реализовано ли это вовсе где-то ещё в репозитории (вне списка пакета), или это целиком новая работа.
- Ширина и позиционирование оглавления на десктопе (липкий сайдбар 190px, фича 6): CSS `.meta-group`/`.timestamps` не входил в список файлов пакета — подтверждена только логика подсветки (`rootMargin`, ui.js) и то, что контейнер — `<details>`; собственно ширина/sticky-позиционирование на десктопе не проверялись.
- Кнопка копирования кода с подписью языка (часть фичи 7): не встречена в прочитанном диапазоне `lightbox.js:1-60`; могла бы жить в отдельном файле/CSS, не входившем в список пакета — не проверялось.
- Контейнер таблиц как «прокручиваемый» (часть фичи 7): подтверждено только текстом докблока `lightbox.js:1-14`, сам CSS контейнера — за пределами заданных 60 строк, не проверялся.
