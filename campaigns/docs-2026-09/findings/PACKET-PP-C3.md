## Цель

К каждой строке инвентаря добавить седьмую колонку «решение» так, чтобы
ни одна строка не осталась пустой (PLAN P.5, R-17). Решение — одно из:

| Решение | Когда | Форма |
|---|---|---|
| перенесён | утверждение (команда, флаг, путь, таблица манифеста) есть в тексте новой страницы или её секции | `перенесён → <раздел>/<страница>#<якорь>` — якорь секции из индекса; `#root`, если совпадение в первом абзаце |
| перенесён (справочник) | тип `cmd` или `flag`, метка `живо`, и команда входит в список `derived kind="cli-help"` страницы `reference/commands` (там каждая команда `vibe` выводится из `--help`; флаг команды покрыт её `--help`) | `перенесён → reference/commands#<секция>` — секция, в которой стоит `derived` этой команды |
| снят: устарело | метка `устарело` | `снят: устарело` |
| нужен автор | метка `живо` или `неизвестно`, но утверждение не найдено ни на одной странице и не покрыто справочником | `нужен автор: <одно предложение — что именно не покрыто>` |

Порядок проверки для строки: сначала точное вхождение утверждения в
страницах (команды — по префиксу `vibe <подкоманда>` без флагов; флаги —
по точному токену вида `--name`; пути — по точной строке и по имени файла;
секции — по точной строке `[table]` или `[[table]]`); затем справочник;
затем метка `устарело`; остальное — «нужен автор». Если утверждение найдено
на нескольких страницах, назвать одну — ту, где оно объяснено, а не
упомянуто (страница раздела `model`/`howto`/`reference` предпочтительнее
`glossary`/`faq`).

Метка `неизвестно`: сначала попытаться разрешить самостоятельно одной
командой `target/debug/vibe.exe <команда> --help` (только `--help`, ничего
другого); если команда есть — строка считается `живо` и идёт по общему
порядку; если нет — `снят: устарело`. В отчёт — список таких переоценок.

## Как делать

Работа механическая: скрипт (Python, stdlib), который читает инвентарь,
грузит текст страниц (XML как текст достаточно), применяет порядок
проверки и переписывает файл с седьмой колонкой; спорные случаи — в отчёт.
Заголовок таблицы: добавить `| решение |`. Никакие другие колонки и строки
не меняются; порядок строк сохраняется; кодировка UTF-8, переводы строк
LF.
