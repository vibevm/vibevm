## Ответы

**Как сегодня считается долг судейства.** Единственный скрипт с этим
именем в дереве (`find campaigns -iname '*judging*'` → ровно один файл):
`campaigns/packages-2026-09/tasks/judging-debt.py`. Источник данных —
`campaigns/packages-2026-09/run/cache.json` (14.9 МБ; PROP-047 §5.1
`CACHE-RECORD`: путь, content-hash, маркеры, плюс campaign-поля — verdict
per marker; `TOOL-INCREMENTAL` — это тот же кэш, что строит `vibe progress
scan`). Алгоритм (`judging-debt.py:71-96`): для каждого файла в
`cache["files"]` берёт «адресуемые» факты из зеркала `run/mirror/<path>.json`
(`addressable()`, строки 45-56 — маркированные, заякоренные факты блока) и
сравнивает с `campaign.verdicts` того же файла — три независимых счётчика:
UNJUDGED (факт есть, вердикта нет, строки 81-83), ORPHANED (вердикт есть,
факта уже нет, строки 85-89), STALE (`processed_hash != content_hash`,
строки 91-92). Файл без зеркала пропускается из подсчёта целиком
(`missing_mirror`, строки 65, 75-77) — «нет зеркала» ⇒ «нет долга» для
этого файла, без явного списка.

Какие файлы вообще попадают в `cache.json` определяет не сам скрипт, а
единый corpus-scope — `facts.toml` (`include`/`exclude`, корень репозитория)
плюс всегда-включённые `DEFAULT_EXCLUDES`/`DEFAULT_EXCLUDE_FILES`
(`crates/progress-core/src/scope.rs:22-46`: компоненты пути `vibedeps`,
`.vibe`, `refs`, `fixtures`, `campaigns`, `target`, `node_modules`, `vendor`;
имя файла `LICENSE.md`). Это единственный сегодня существующий механизм
исключения, и он один на весь проект: PROP-047 §2 (`CONFIG-MOVED-TO-FACTS`,
строки 22-29) прямо фиксирует, что scope — «facts-layer concern» и что
«the campaign toolchain merely consumes the same scope through the facts
core». То есть у долга судейства сегодня нет отдельного от общего corpus
понятия исключения: убрать файл из `facts.toml` = убрать его одновременно
из `facts check`, из карты (`specmap`) и из подсчёта долга — сегодня их
нельзя развести, а именно это и требуется постановкой задачи для
doc-пакетов.

как правку одного Python-файла, а как будущий ключ в `facts.toml`/`vibe
progress`.

(б) — точнее всего ложится в философию «долг — перечислимый список,
судится по факту, не по файлу целиком» (`DEBT-IS-A-LIST-NOT-A-RATIO`) и в

сейчас».

освобождают документационно-тяжёлые пакеты других kind.
