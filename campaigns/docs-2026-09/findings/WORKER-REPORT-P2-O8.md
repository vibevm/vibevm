## A2.16 — гейт покрытия (`075a5d6b`)

**Файлы.** `crates/vibe-doc/src/coverage.rs` + `coverage/tests.rs`
(новые), `crates/vibe-doc/src/lib.rs`,
`crates/vibe-doc/src/manifest/page.rs`,
`crates/vibe-cli/src/{cli/doc.rs,commands/doc.rs}`,
`crates/vibe-cli/src/commands/progress/grounding.rs`,
`crates/vibe-facts/tests/judging_exempt.rs`, `facts.toml`.

**Обязательство** — факт с `actionstage="doc"` **и** аудиторией. Обе
половины нормы: стадия говорит, что обещание документационное, аудитория
— кому оно дано. Маркер `actionstage="doc"` без аудитории обязательством
**не** считается: пустой список — это молчаливое умолчание словаря
(`dev`), то есть отсутствие решения, а не решение (`##OBS-COVERAGE-GATE`
связывает обещание с теми, кому оно дано).

**Аудитория — половина вопроса, и она отчитывается отдельно.** Гейт
различает два состояния: «адрес не цитирует никто» и «цитируют, но ни
одна страница не для этой аудитории», и во втором случае называет
страницы, которые цитируют. Это разный ремонт: пометить существующую
страницу или написать новую.

**Откуда берутся половины.** Обязательства — из той же grounding-ячейки,
через которую входит каждый глагол `vibe facts`: те же `include`, те же
исключения, та же диспетчеризация словаря по виду пакета. Второе
перечисление корпуса дало бы гейту корпус, которого никто больше не
видит. Цитаты — из самих страниц (`citations::edges`), а не из
закоммиченной карты: гейт, читающий сгенерированный артефакт, зелен
всякий раз, когда артефакт пуст или протух.

**Сверка сторон.** Обязательство несёт путь относительно корня корпуса,
ребро — `spec://`-адрес; обе стороны канонизируются через
`fs::canonicalize` (на Windows два написания одного файла различаются не
только разделителем), с мемоизацией по адресу.

**Порог.** `--min <процент>` для промежуточных прогонов; стандартная
планка — 100 %. Непрочитанная пивотом страница не проходит **никогда**:
её цитаты неизвестны, а неизвестное — не покрыто.

### Хвост P2-O3: фикстуры раннера вышли из наблюдения

`facts.toml` получил один `exclude`:
`vibevm/vibepacks/org.vibevm.core/vibevm-docs/*/examples/**`. Фикстуры —
не документация дважды: это **копии** пакетов, которые проект уже
наблюдает по их собственным путям (пометить копию — пометить одно
утверждение дважды), и это **вход** проверки, а не утверждение, в котором
проект мог бы ошибиться (линия F-096). Счёт вернулся с 380 к **372**
(= 325 базовых + 47 файлов руководства на тот момент); сегодня, после
новых страниц соседнего воркера, `376`.

Исключение прибито тестом
`a_documentation_packages_fixture_trees_are_not_observed`
(`crates/vibe-facts/tests/judging_exempt.rs`) — рядом с тремя
существующими стражами того же файла: он ходит по `examples/` каждого
in-tree `doc`-пакета и требует, чтобы каждый `.md`/`.xml` там был убран
`exclude`, и отказывается проходить на пустом множестве.

## A2.17 — плейсхолдеры и превью (`6923c7ac`)

**Файлы.** `crates/vibe-doc/src/media.rs` + `media/{image.rs,png.rs,
placeholder.rs,placeholder/{font.rs,raster.rs}}` и их тесты (новые;
`image.rs` — переезд из `vibe-check`), `crates/vibe-doc/src/lib.rs`,
`crates/vibe-check/{Cargo.toml,src/checks/doc_media.rs,…/tests.rs}`,
`crates/vibe-cli/src/{cli/doc.rs,commands/doc.rs}`, `Cargo.lock`.

**Баннер и иконка — встроенный SVG из хэша координаты**: два оттенка на
расстоянии, взятом из того же хэша; один из пяти узоров (полосы, точки,
сетка, лучи, шевроны) при непрозрачности ≤ 0,12 — фон обязан остаться
фоном; глиф — вид пакета, книга для `doc`, свой знак для каждого из
остальных семи. Запрета на SVG это не нарушает: запрещён SVG, который
пакет **везёт** и читателю отдают дословно, а эта разметка составляется
здесь из чисел (R-19, `##CARD-MEDIA-SOURCE`).

**Превью — растр**, и причина не эстетическая: карточку ссылки забирает
краулер, который рендерер не запустит. 1200×630, тот же фон, тот же глиф,
заголовок. Живой результат на руководстве: **61 685 байт** — вчетверо
ниже собственного потолка роли (1 МиБ), то есть сгенерированное превью
проходит ту проверку, которой его будут судить (тест это и утверждает).

**Писатель PNG свой, и это решение, а не изобретение велосипеда.**
Производный артефакт — это байты: один и тот же вход обязан давать один и
тот же файл на всякой машине и при всякой конфигурации сборки. Общий
компрессор этого не обещает — дерево уже теряло на этом golden-корпус
(аномалия P2-O1 №1: бэкенд gzip менялся от состава графа сборки). Поэтому
один блок, фиксированная таблица Хаффмана RFC 1951 §3.2.6 (выбирать
нечего, значит и ничью разрешать нечем), совпадения только на расстоянии
1, фильтр `Sub` выбран, а не найден перебором — после него плоская строка
это строка нулей, из которых карточка и состоит.

Писатель **проверяется чтением**: тесты несут собственный инфлятор
фиксированного блока и разбирают каждый чанк с CRC. Энкодер, проверенный
своими же ожиданиями, не проверяет ничего.

**Шрифт встроенный по той же причине**: файл шрифта — зависимость от
того, чего пакет не везёт. 5×7, капитель, цифры и пунктуация заголовка;
заголовок, который лицо набрать не может (кириллица), становится **не
заголовком**, а не мусором — карточка показывает фон и глиф.

**Лимиты D-20 переехали в конвейер.** `##PIPE-LIBRARY` отдаёт библиотеке
всё, в чём есть содержание, а форматы, пропорции и байтовые потолки —
содержание. Ячейка `doc-media` в `vibe check` теперь **рендерит находки,
которых не вычисляет**; `vibe doc check --media` печатает те же. Две
копии байтового потолка — ровно та гниль, за которую дерево уже платило
(рукописный двойник парсера манифеста в сканере индекса). `vibe-check`
получил зависимость `vibe-doc`; цикла нет — `vibe-check` ни от кого,
кроме `vibe-cli`, не требуется.

**Публикация** копирует картинку под именем из её содержимого (первые 16
hex SHA-256 + расширение, которое заслужил **формат**, а не имя файла) и
ничего не перекодирует. Отсюда же следует, почему проверка исходного
пакета — это проверка опубликованного.

## A2.18 — `vibe doc` и крейт `vibe-doc-server` (`c3983882`)

**Файлы.** `crates/vibe-doc-server/**` (новый крейт),
`crates/vibe-doc/src/build.rs` + `build/tests.rs` (новые),
`crates/vibe-doc/src/{lib.rs,coverage.rs}`,
`crates/vibe-cli/{Cargo.toml,src/cli/doc.rs,src/commands/doc.rs}`,
`Cargo.toml`, `Cargo.lock`, `conform.toml`, `DEV-GUIDE.md`.

**Четыре глагола**: `build`, `check`, `manifest`, `serve` — тонкие
поверхности над библиотекой. Часы зовутся ровно в одном месте на глагол:
сборка, зовущая `now()` глубже, выдавала бы разные байты для одного
дерева.

**`build` — один обход.** Страницы, манифест, четыре тира `llms` и
картинки карточки — свёртки одного `PageSet` по адресам, которые
фиксирует `##SITE-MOUNT`: остров в каталоге со слэшем, проекции рядом
файлами, машинные файлы в корне. Живой прогон на руководстве: **56
файлов, 2 900 017 байт, 3 сгенерированных плейсхолдера, 0 нечитаемых
страниц**.

**`serve` — свой крейт.** axum не должен оказаться рядом с конвейером:
`vibe-doc` линкуют генератор сайта, MCP-инструменты и каждая проверка.
Форма `vibe-index` повторена (axum 0.8, один строитель роутера, RFC 7807,
тесты через `oneshot` без слушателя), код не заимствован — этого требует
`##PIPE-CRATES`, и манифесты объясняют почему.

**Слушает петлю, и флага на это нет.** Хост — не настройка: читатель
отдаёт документацию проприетарных пакетов, и достижимый с другой машины
отдаёт её туда. Проверено вживую: `netstat` показывает
`TCP 127.0.0.1:8477 LISTENING`.

**Форму `##LOCAL-STATIC` не повторяет.** Роутер сопоставляет **сырой**
путь, а экстрактор декодирует захват уже после совпадения — так проба
фазы 0 наблюдала, как живой сервер отдаёт файл выше своего корня. Здесь
адрес декодируется **первым**, разбивается самим сервером, и сегмент,
который не ровно одно обычное имя, до файловой системы не доходит. Три
написания атаки — тесты; живая проба даёт `400`.

**`--lang` — не переключатель.** Один doc-пакет — один язык, поэтому флаг
не выбирает внутри пакета: он заявляет, какой язык нужен, и отказывает,
называя координату адаптации (`<имя>-<язык>`). Молчаливая сборка не того
языка — это страница сайта на языке, которого никто не просил.

**Крейт заведён по чеклисту §2.8 целиком**: оба списка workspace,
`license-file.workspace`, `publish = false`; `specmark::scope!` первой
строкой каждого модуля; один `thiserror`-enum с `#[spec(implements)]`,
сообщения цитируют `spec://` и несут `fix:`; доктесты на `Config`,
`Reader`, `build_app`, `serve`, `ApiError::not_found`; крейт вошёл в
`gated` (не в `exempt`) — `cargo xtask conform check` по нему **ноль
находок**; `cargo xtask specmap` — 0 suspects, 0 гейтед-сирот. README
есть. Отдельный шаг панели не нужен: шаг 1 (`cargo test --workspace`)
берёт новый крейт автоматически.

`DEV-GUIDE.md` §8 переписан тем же коммитом (R-11): что спрашивает каждая
проверка, две неожиданности `build` (запускает продукт; пишет адресную
карту) и почему у читателя нет флага хоста.

## A2.19 — документация в карте и `read_doc` (`7f919413`)

**Файлы.** `crates/vibe-doc/src/agent.rs` + `agent/tests.rs` (новые),
`crates/vibe-doc/src/lib.rs`, `crates/vibe-mcp/{Cargo.toml,
src/tools.rs,src/tools/read_doc.rs,src/tools/read_doc/tests.rs,
src/skill_template.md,tests/tools_oracle.rs}`,
`crates/vibe-trace/{Cargo.toml,src/docscan.rs,src/lib.rs,src/search.rs,
src/select.rs}`, `Cargo.lock`.

**Документация входит через карту, без новых инструментов для этого.**
`HostDocScanner` компонуется с встроенным набором в тех трёх местах, где
`vibe-trace` строит карту в памяти: `explain`, `query`, `select`. Живо:

```
$ vibe explain "spec://org.vibevm.core/vibevm/common/PROP-057#LOCAL-SERVE"
  edges in:
    documents ← `howto::read-documentation-locally` (…/howto/read-documentation-locally.xml:14)
$ vibe query --kind doc-page --limit 3
showing 3 of 48 matching
```

**Где лежат страницы — обход, а не список.** Список doc-пакетов протухает
в день, когда кто-то открывает перевод, а дерево уже говорит, какие
пакеты документация: каждый in-tree слот спрашивается как TOML-данные
(строгий разбор уронил бы пакет из-за поля, которого этот обход не
читает, и его страницы молча выпали бы из карты).

### Отступление, которое важно прочитать: хостовый `specmap.json` не тронут

`##PIPE-EDGES-HOST-SIDE` требует инъекции в обе точки
`xtask/src/specmap.rs`. Я её **не сделал**, сознательно:

- движок не чеканит spec unit для факта внутри ячейки таблицы (аномалия
  P2-O6 №1, четыре живых цитаты руководства: `PROP-008#ROW-*`,
  `PROP-002#ROW-GS-BRANCH-MEANING`);
- эти адреса начинаются с хостового префикса, значит resolve-гейт
  `xtask/src/specmap.rs` посчитал бы их **блокерами** под `--check` — то
  есть панель стала бы красной на якорях, которые существуют;
- починка лежит в вендоренном движке (R-21), мне закрыта;
- мой гейт покрытия читает страницы напрямую и потому «зелёным от
  пустоты» быть не может вовсе — обоснование, которым норма эту инъекцию
  мотивирует, выполнено другим способом.

Три запроса (`explain`/`query`/`select`) строят карту **свежей**, без
resolve-гейта и без ратчета, и это ровно то место, где документации
место, пока движок не научится узлу в ячейке таблицы. Кандидат в
`BACKLOG.md` строкой `docs:`.

**`read_doc`** — единственное, чего карта не умеет: отдать саму страницу.
Возвращает **проекцию**, никогда остров: разметка для браузера — это
токены, за которые агент платит и которых не читает. `md` подставляет
текущий текст каждого процитированного правила, `xml` сохраняет адреса.
Обе несут те же `pNN`, что и сайт. `lang` — запасной путь, не
переключатель: ищет `<имя>-<язык>`, а если этой машины он не достиг —
отвечает источником и **говорит**, каким языком ответил.

## A2.20 — скилл (`41c02fe0`)

**Файлы.** `crates/vibe-mcp/src/skill_template.md`,
`crates/vibe-agent-projection/src/pkgskill/projection.rs` +
`projection/documentation.rs` (новый) + `projection/tests.rs`.

`[[skill]]` в манифесте руководства уже был (A3.1) — проверено чтением.
Встроенный `vibevm` получил абзац-указатель (пакет, его скилл,
`read_doc`, `vibe doc serve`) и фразу, что ничего ниже от него не
зависит: скилл, предполагающий необязательный пакет, вводит в заблуждение
того, у кого его нет.

**`vibe skill list` руководство не видел вовсе.** Инвентарь собирается из
lock-файла, а `doc` — единственный вид, который `vibe install` по закону
отказывается ставить: документацию читают, а не устанавливают
(`##KIND-DOC-NOT-INSTALLED`). Скилл руководства был бы невидим навсегда.
Добавлен третий проход — in-tree реестр проекта, и только для пакетов
вида `doc`: обычный пакет доходит до агента установкой, и взятый из двух
мест дал бы одну проекцию под двумя origin. Живо:

```
$ vibe skill list
  → vibevm-docs [doc:vibevm-docs] → agents: all — Find the page, the rule or the prompt …
10 skill(s) declared.
$ vibe skill install --skill vibevm-docs --scope project --dry-run --assume-yes
  → would-create vibevm-docs → claude (project) …/.claude/skills/vibevm-docs
```

**Чего этот путь не достаёт** — руководства, прогретого в машинный store
на машине потребителя. Это природа store (он на машину, а команда на
проект), и `##KIND-DOC-KNOWN-LIMIT` прямо выводит объявление «эта
документация консультируется» за пределы волны; до него потребитель
читает прогретое руководство через `vibe doc serve` и `read_doc`, которым
объявление не нужно. Это отступление от буквы пакета («после `vibe cache

## Хвост A2.5 — два правила гейта (`d40225e1`)

**Файлы.** `crates/vibe-check/src/checks/doc_translation.rs` + `…/tests.rs`.

1. **Непустой `[i18n].available` у `doc`-пакета — ошибка.** Поле
   перечисляет языки, которые несёт **один** пакет; у документации

   `translates` при каждом рендере, не согласился бы с манифестом о том,
   что существует. Правило только для вида `doc`.
2. **Источник перевода ищется и в предках проверяемого корня.** Адаптация
   в разработке проверяется двумя способами, и только у первого корень
   пакетов под ногами; второй сообщал «источник недоступен офлайн» про
   пакет тремя уровнями выше в том же дереве — предупреждение, которое
   учит игнорировать предупреждения.

1. **Мой атом A2.19 покрасил три документированных примера.**

   стал делать то, что страница про него говорит. Перевыпустил их **не

   этот якорь цитируют — то есть следующая новая цитата снова покрасит
   пример. Кандидат: выбрать для этих примеров якорь, который
   документация не цитирует.
2. **Хостовый `specmap.json` я не коммитил** (0 suspects, 0 сирот, 0

   коммит после посадки волны.
3. **Трипвайр раннера ловит чужую сессию.** Первый полный прогон

   документации. Кандидат: исключить `steward/` из наблюдаемой половины
   трипвайра (это не то, куда пишет `vibe`).

   находками** — 28 новых против базовой линии, все не мои: `file-length`
