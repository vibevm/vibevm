Algorithm: heading = format!("## [{name}]"); walk `changelog.split_inclusive('\n')` keeping a byte offset `pos` (pos += line.len() after each line); start = None; for each line: if start is None and line.trim_start().starts_with(&heading) set start = Some(pos + line.len()); else if start is Some and line.trim_start().starts_with("## [") set end = pos and stop. end defaults to changelog.len(). **Decisions already made.**
- Layout (forced by conform max_file_lines = 600, which applies to xtask; main.rs is at 600, release/tests.rs at 599, release.rs at 592): extractor in xtask/src/dist/changelog.rs as `pub(crate) mod changelog;` of dist, called crate::dist::changelog::section; body/cap/read code in new xtask/src/dist/release/notes.rs; prepare tests in new xtask/src/dist/release/tests/prepare.rs. xtask/src/main.rs is not touched.

- section() returns a borrowed slice located by byte offsets over split_inclusive('\n'); heading match is `trim_start().starts_with("## [<name>]")` (closing bracket included, so 1.0.1 never matches 1.0.11), dated or not; the heading line is excluded; the result is .trim()med, which also drops any \r from CRLF files; empty means None.
- CHANGELOG.md is read from the release commit via read_commit_file, not from the working tree.
- Refusal text exactly: "dist prepare: CHANGELOG.md has no `## [<version>]` section; date the [Unreleased] section as <version> before preparing" (version via Version's Display).
- Body = section + "\n\n" + "Mutable vibevm <version> distribution. Verify downloads through `DISTRIBUTIONS.json`." (name from DISTRIBUTION_AGGREGATE_MANIFEST_FILENAME).
- Cap: 125000 characters (GitHub's release-body limit), counted in chars; truncation marker "\n\n… truncated; full notes: https://github.com/vibevm/vibevm/blob/v<version>/CHANGELOG.md" placed before the footer.
