**Decisions already made.**
- The flag is the global `--operation-id ID` with field `operation_id`, because `vibe app resume --operation ID` already exists and a same-id global would capture its value.
- The record home is the settings root as the process started, before composition::promote_user_config_env (which may set VIBE_SETTINGS from user config). record_home() pins it in a OnceLock on the first call, which begin makes at the top of every run; OPS-5 and OPS-8 read through record_home() too, so writer and readers agree.
- The record lives at record_home()/operations/<ID>.json, written by temp file plus rename (0600 on Unix through NamedTempFile).
- machine, pid and started come from vibe_lifecycle::LeaseHolder::current(), the one place the host name is computed. home is the settings root as a string.
- argv is the arguments after the program name, each passed through redact_credentials, and every `--set ID=VALUE` or `--set=ID=VALUE` value replaced by `***` (the id stays). `--set` is the flag of `vibe install -g` app parameters and `vibe app resume`, documented as carrying ephemeral secrets. OPS-6 compares this stored form.
- documents holds only what went through sink::document; commands that print their JSON report directly are recorded without it, as OPERATION-RECORD-WRITE says.
- invoked_by is the --invoked-by flag only. composition/operation.rs is not an env root, so VIBE_INVOKED_BY is not read here.
- begin runs before every command path, including kit. finish runs in main() after the worker thread joins, so a panic is recorded as failed with exit 101.
- The exit number is recovered by comparing ExitCode values (ExitCode is PartialEq; verified on rustc 1.93).
- Refusal codes are snake_case like the existing ones (lock_hash_mismatch, consent_required): operation_id_invalid, operation_home_unavailable, operation_record_unwritable.
- An existing record with the same ID is overwritten in this entry. OPS-6 changes that.

**Not in this entry.** No `vibe operations` command, no retry or replay, no pruning, no event-line file, no reading of VIBE_INVOKED_BY, and no conversion of commands' direct JSON prints. Do not add helpers that later entries need (read, all, observed).
