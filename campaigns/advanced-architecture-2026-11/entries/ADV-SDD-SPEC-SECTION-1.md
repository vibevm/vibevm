**Steps.**
1. Add `pub mod spec_section;` to crates/vibe-workspace/src/lib.rs, next to the other `pub mod` lines, after `pub mod publish;`.
2. Create crates/vibe-workspace/src/spec_section.rs. Start it with `specmark::scope!("spec://org.vibevm.core/vibevm/modules/vibe-workspace/PROP-035#URI-OBSERVED-SOURCE-READ");`. Define the public types exactly as listed in decisions (ReadOptions, Disposition, SectionRead, RefusalKind, SectionRefusal), with their as_str methods.
3. Implement `pub fn read(project_root: &Path, address: &str, options: ReadOptions) -> Result<SectionRead, SectionRefusal>`. (a) Parse with vibe_spec::SpecAddress::parse. (b) Discover with Workspace::discover(project_root). (c) If `workspace.root.join("vibe.lock")` exists, read it with vibe_core::manifest::Lockfile::read; an absent lock means no packages. (d) Build the world BTreeMap<(String,String), SelectedPackage> and the self coordinate exactly as crates/vibe-cli/src/commands/facts/selected.rs lines 117-145 do: an in-place slot uses vibedeps::in_place_slot_abs_path, any other slot uses vibedeps::slot_abs_path; take the coordinate from [project] first, then [package], else SelfCoordinate::new(None, String::new()).
4. Resolve the file: `let resolver = FileResolver::with_selected_world(&workspace.root, &workspace.root, world.clone(), self_coordinate.clone()); let path = resolver.resolve_file(&addr)`, mapping every ResolveError variant per decisions. Read the text: `let source = FsSectionSource::new(resolver); let mut text = source.section_text(&addr)`, mapping the String error per decisions. When options.expand_embeds is true, run `text = vibe_spec::expand_embeds(&text, &source)` and map its error to UnreadableSource with message `embed expansion failed: {e}`.
5. Compute the origin per decisions. Use the self-coordinate test from decisions to choose the root, version and disposition. file = path.strip_prefix(root), with the components joined by '/'; if that fails, retry with root.canonicalize(); if it still fails, refuse with OutsidePackage. format = "xml" when file ends with ".xml", else "markdown". sha256 = vibedeps::sha256_bytes(text.as_bytes()).
6. Write crates/vibe-workspace/tests/spec_section.rs with the nine tests named in `test`, then run the check.

**Decisions already made.**
- Module path: `vibe_workspace::spec_section`. Function: `pub fn read(project_root: &Path, address: &str, options: ReadOptions) -> Result<SectionRead, SectionRefusal>`. The address is a &str so that vibe-mcp needs no vibe-spec dependency.
- `#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)] pub struct ReadOptions { pub expand_embeds: bool }`.
- `#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)] #[serde(rename_all = "lowercase")] pub enum Disposition { Authored, Converted, Copied }` with `pub fn as_str(self) -> &'static str` returning "authored"/"converted"/"copied".
- `#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)] pub struct SectionRead { pub ok: bool, pub command: &'static str, pub address: String, pub package: String, pub version: Option<String>, pub file: String, pub format: &'static str, pub disposition: Disposition, pub sha256: String, pub text: String }`. Keep exactly this field order. ok is always true. command is always "show section". address is the input string, unchanged. package is "<group>/<name>".
- `#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)] #[serde(rename_all = "kebab-case")] pub enum RefusalKind { InvalidAddress, NotInstalled, VersionMismatch, DocNotFound, AnchorNotFound, OutsidePackage, UnreadableSource }` with `pub fn as_str(self) -> &'static str` returning invalid-address, not-installed, version-mismatch, doc-not-found, anchor-not-found, outside-package, unreadable-source.
- `#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)] #[error("{message}")] pub struct SectionRefusal { pub kind: RefusalKind, pub message: String }`.
- A SpecAddress::parse error → InvalidAddress, with message = error.to_string().
- ResolveError mapping: an exhaustive match with no wildcard arm, message = error.to_string(). LegacyHostAuthority, PatternNotExpanded → InvalidAddress. UnselectedPackage, PackageSlotNotFound → NotInstalled. SelectedVersionMismatch, SelfCoordinateVersioned → VersionMismatch. DocNotFound → DocNotFound. InvalidLookupPath → OutsidePackage. SourceObservation, AmbiguousDoc, PairCollision, ActiveFormatCollision → UnreadableSource.
- section_text String error: a string starting with "anchor not found" or "ambiguous requested anchor path" → AnchorNotFound; anything else → UnreadableSource. message = the string.
- A Workspace::discover or Lockfile::read failure → UnreadableSource, with message = error.to_string().
- Self-coordinate test: the address is the self coordinate when `addr.authority` is `vibe_spec::Authority::Package { group, name, .. }` with `Some(group) == self_coordinate.group.as_ref()` and `name == &self_coordinate.name`. Never decide this by string-prefix matching on the address, by whether the world lacks the key, or by comparing the resolved path with workspace.root. Every other Package authority is looked up as `world[&(group.clone(), name.clone())]`; it is always present once resolve_file has succeeded, because Host authorities were already refused there. `package` = `format!("{group}/{name}")`, built from the address authority.
- Self coordinate origin: root = workspace.root and disposition = Authored. Version: root_manifest.project → Some(project.version.clone()); else root_manifest.package → Some(package.version.to_string()); else None. The file is relative to the workspace root, e.g. vibevm/vibespecs/common/OWN.md.
- Dependency origin: root = the selected package's root, and version = Some(selected.version as a string). Disposition comes from the vibedeps::read_slot_record(root) row whose `path == file`: a row with disposition Converted → Converted; Copied → Copied; a row with no disposition, no matching row, or a read_slot_record error → Copied.
- The version comes only from the world the lock selects. The resolver refuses a differing @version; nothing is fetched. `~rN` pins are not checked.
- By default #embed is not expanded. No pagination, cursors or proof labels.
