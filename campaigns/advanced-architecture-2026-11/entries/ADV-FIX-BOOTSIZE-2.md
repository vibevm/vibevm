**Decisions already made.**
- JSON field names: `state` with values exactly "present", "absent", "unreadable"; `error` is the `std::io::Error` Display text verbatim, emitted only when state is "unreadable".
- An absent static lane stays `"static_md": null` (unchanged); an unreadable static lane becomes an object with present false, bytes 0, lines 0, contributions [], state "unreadable", error. The index lane object is always emitted, as today.
- Unreadable means any read error other than NotFound, including invalid UTF-8 (`read_to_string` InvalidData). It is a reported state, never a command failure: exit code 0.
- The wire path of an unreadable static lane is `static_wire.clone().expect("static path resolved when the lane file exists")`; `static_wire` is `Option<String>` and is Some whenever `static_path` is Some, which is the only way to reach Present or Unreadable.
- Schema stays v1 (`SCHEMA_VERSION` unchanged); the new properties are optional, so older documents remain valid.
