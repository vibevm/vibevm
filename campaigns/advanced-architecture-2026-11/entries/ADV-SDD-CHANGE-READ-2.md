1. Create crates/vibe-requirements/src/change/drift.rs with first item `specmark::scope!("spec://org.vibevm.core/vibevm/common/PROP-071#CHANGE-ORIGIN-CAPTURE");`. Define `#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)] #[serde(rename_all = "kebab-case")] pub enum CaptureStatus { Matched, Stale, Missing, Unavailable }`. Define, each with `#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]`, `ChangeCaptureRow { pub declared: String, pub actual: Option<String>, pub status: CaptureStatus }`, `ChangeCitationRow { pub address: String, pub declared: String, pub actual: Option<String>, pub status: CaptureStatus }` and `ChangeOriginRow { pub package: String, pub locked_version: Option<String>, pub manifest: ChangeCaptureRow, pub documents: Vec<ChangeCitationRow> }`.
2. In drift.rs add `pub(crate) fn origin_rows(selected: &vibe_workspace::SelectedWorkspace, manifest: &vibe_core::manifest::change::ChangeManifest) -> Result<Vec<ChangeOriginRow>, SavedChangeError>`. Let `ws = &selected.workspace`. Open `let project = vibe_safefs::Project::open(&ws.root).map_err(|_| SavedChangeError::Unavailable("project lock"))?;` and call `project.read_source_bytes("vibe.lock")`; an `Err` maps to `SavedChangeError::Unavailable("project lock")`. `Ok(Some(bytes))`: `std::str::from_utf8(&bytes)` then `vibe_core::manifest::Lockfile::parse_str(text)`; either failure maps to `SavedChangeError::Unavailable("project lock")`. `Ok(None)` means there is no lock. An UNAVAILABLE origin row is: `locked_version: None`, manifest `ChangeCaptureRow { declared: origin.manifest_sha256.clone(), actual: None, status: Unavailable }`, and one `ChangeCitationRow { address, declared: doc.sha256.clone(), actual: None, status: Unavailable }` per declared document. For each origin in `manifest.origins()` (declared order): no lock gives an unavailable row. Otherwise `vibe_core::PackageRef::parse(&origin.package)`; an `Err`, or `pin.group` being `None`, gives an unavailable row (no unwrap). Then `lock.find(&group, pin.name.as_str())`; `None` gives an unavailable row.
3. For a locked row `row`: the slot is `vibe_workspace::vibedeps::in_place_slot_abs_path(&ws.root, &row.group, row.name.as_str())` when `row.materialization.is_in_place()`, otherwise `vibe_workspace::vibedeps::slot_abs_path(&ws.root, &row.group, row.name.as_str(), &row.version)`. `locked_version` is `Some(row.version.to_string())`. Define a private helper `fn capture(project: &Project, ws_root: &Path, file: &Path, declared: &str) -> (Option<String>, CaptureStatus)`: `file.strip_prefix(ws_root)` failing gives `(None, Missing)`; otherwise `project.read_source_bytes(&vibe_core::machine_json_path(relative))`; `Ok(None)` or `Err(_)` gives `(None, Missing)`; `Ok(Some(bytes))` gives `actual = format!("sha256:{}", vibe_workspace::vibedeps::sha256_bytes(&bytes))` (sha256_bytes returns lowercase hex without prefix) and status `Matched` when `actual == declared`, else `Stale`. The manifest capture is `capture(..., &slot.join("vibe.toml"), &origin.manifest_sha256)`.
4. Documents of a locked origin: host coordinate `let coord = manifest.coordinate();` and `let self_coord = match coord.split_once('/') { Some((g, n)) => vibe_spec::SelfCoordinate::new(Some(g.to_string()), n.to_string()), None => vibe_spec::SelfCoordinate::new(None, coord.to_string()) };` (a project with no group has a coordinate without '/'; that is not an error). Build `let mut map = std::collections::BTreeMap::new(); map.insert((row.group.to_string(), row.name.to_string()), vibe_spec::SelectedPackage::new(row.version.to_string(), slot.clone()));` and `let resolver = vibe_spec::FileResolver::with_selected_world(&selected.selected_root, &ws.root, map, self_coord);`. For each declared document: `let resolved = vibe_spec::SpecAddress::parse(&doc.address).ok().and_then(|a| resolver.resolve_file(&a).ok());` (no `?`: SavedChangeError has no From<SpecAddressError>). `None` gives `actual: None, status: Missing`; `Some(path)` gives `capture(..., &path, &doc.sha256)`.

  <p><CHANGE-ORIGIN-CAPTURE fact="true" status="impl/done">An origin capture names bytes of the origin package as the selected project has it installed. manifest_sha256 is sha256: followed by the lowercase hexadecimal SHA-256 of the exact bytes of vibe.toml at the root of the origin package's materialised slot. A document capture's sha256 is the same digest of the exact bytes of the whole file its cited address resolves to in that slot, not of the cited section alone; the fragment selects no narrower byte range. The origin package is found by group and name in vibe.lock, and its slot is the one that lock row selects. Drift compares each capture with those bytes now: matched when equal, stale when different, missing when the package is locked but the manifest or document file cannot be resolved or read, unavailable when the project has no lock, the lock has no row for the package or the pin cannot be read as a grouped package. The locked version is reported beside the declared pin; a version difference alone is not a status. The check report, protocol vibe-change-check/1, fails a change on any declaration or read refusal and on any stale or missing capture; unavailable captures do not fail it. Drift never fetches, installs or authenticates an origin.</CHANGE-ORIGIN-CAPTURE></p>
```

**Decisions already made.**
- A capture covers whole materialised files in the lock-selected slot (owner question 1). Hashes are compared as the full `sha256:<hex>` string.
- The status words are the existing EvidenceStatus spellings (matched, stale, missing, unavailable). A local enum carries them so vibe-wire is not coupled to change drift. No `unstable` word and no version-differs status.
- Read-only: lock and slot bytes are read through vibe_safefs::Project::read_source_bytes. No sync, install, network or slot-record write. An in-place slot that the no-follow reader refuses reads as missing.
- The origin's kind prefix is ignored when matching the lock row (identity is group and name, PROP-008).
- Fallible-call mappings (no unwrap in production): Project::open or lock read/UTF-8/parse failure -> `SavedChangeError::Unavailable("project lock")`; PackageRef parse error or no group -> that origin row unavailable; lock row absent -> unavailable; a coordinate without '/' -> `SelfCoordinate::new(None, coordinate)`; strip_prefix failure, address parse error, resolve error, absent or unreadable file -> that capture missing.
- Entry 1 runs first; this entry edits report.rs, mod.rs and PROP-071 after it, one after another.
- clippy -D warnings: every new pub item is re-exported or used; origin_rows is pub(crate) and called by change_report; no dead fields.
- File budgets: drift.rs, check.rs and drift_cases.rs are new and stay under 600 lines; report.rs grows by about 3 lines.

**Not in this entry.** Looking up the cited anchor inside the document, per-need requirements-query axes, a version-differs status, authenticating origins, and any CLI or MCP surface.
