**Decisions already made.**
- AgentTypesError variants:
```
#[error("`{}` was not generated by vibe; vibe writes no subagent type without its own ignore file — rename or delete it", .path.display())]
ForeignIgnoreFile { path: PathBuf },
#[error("I/O error on `{}`: {reason}", .path.display())]
Io { path: PathBuf, reason: String },
```
- One algorithm for both modes:
(1) For each spec, existing = read_file(spec.file()) and resolved = resolve(&spec.body).
(2) If any resolved is Ok, read .claude/agents/.gitignore. If it is present and its first line (up to the first \n, without \r) != AGENT_TYPES_IGNORE_FIRST_LINE, return Err(ForeignIgnoreFile) before writing anything, in both modes. Write mode: when it is absent or != AGENT_TYPES_IGNORE_BODY, write_atomic it. Check mode: ignore_current = (bytes == AGENT_TYPES_IGNORE_BODY).
(3) Give each spec an outcome as below.
- Write outcomes:
- existing Some and !is_generated_agent_type -> Foreign, no write.
- resolved Err(r): existing generated -> remove_file, Removed, reason Some(r); otherwise Unavailable, reason Some(r).
- resolved Ok(b): desired = render_claude_agent_type(spec, &b). existing None -> write_atomic, Created; existing == desired -> Unchanged; otherwise write_atomic, Updated.
- Check outcomes (nothing is written or removed):
- Foreign as in write mode.
- Err + generated existing -> Stale with reason.
- Err + absent -> Unavailable with reason.
- Ok + absent -> Missing.
- Ok + different -> Stale.
- Ok + equal: ignore_current -> Current; otherwise Stale with reason "`.claude/agents/.gitignore` is missing or out of date, so this file is not kept out of Git".
- Only the files named by the given specs are touched; other files in .claude/agents (for example a tracked opus5.md) are never read or changed.
