# Role, classification and observability source review

Reviewed interval: architecture-baseline-2145ec8d1 to
architecture-after-3ffb13b29. Four commits modify nine product paths: seven
governing sources, one test citation and the canonical index.

The new invocation-role law makes create authored-code production, build
deterministic assembly and ordinary/scoped verify exact-subject verification
without hidden production or implicit missing-tool builds. The old phase table
and commissioned boundary mechanics remain historical descriptions. An explicit
full pass owes causal build/check of the produced source followed by verification
of that current subject; a build before changed producer output is insufficient.
Prerequisites, relay, resume, clean composition, handler powers and phase position
cannot supply absent producer authority. External orchestration stays external.

Classification now precedes format dispatch. Native Vibe specs, structured
ordinary CommonMark, XML data and opaque foreign bytes keep distinct semantics;
suffixes do not mint facts or addresses. Existing canonical parsers remain owners.
Boot costs are diagnostic, never admission quotas or thresholds; calculator
provenance/incompleteness and pre-install marginal what-if remain desired work,
separate from worker execution budgets.

Navigation/refactoring graph proposals retain their own domain rather than
replacing resolver/compiler/registry/journal authority. Every meaningful supported
operation/model owes typed external access and ETO, with provenance, privacy and
independent availability/implementation/authorization/observation axes. No IDE,
plugin, MVP, new parser, scheduler, native ABI or implemented facade is claimed.

Independent review found a stale unconditional relay rationale; it was corrected
and re-reviewed. Two changed semantic section revisions were advanced. The
unchanged park/drain test now cites the unchanged revision-4 directory contract,
not the broader changed relay role. That citation changes no behavior or user
guidance; its two no-impact dispositions are separately justified. The index
likewise introduces no delivered user operation or guidance.

Existing status attributes preserve commissioned facts and proposal/work status;
the three added spec/done anchors state accepted source policy, not implemented
guards. Mutable local 1.1.0, DP1 users/history, independent epochs and the public
distribution hold remain intact. Later runtime, native, documentation and full
programme conformance are still required.
