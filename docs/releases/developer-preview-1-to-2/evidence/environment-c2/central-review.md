# M-14-C.2 physical target fence review

This acceptance covers the physical fence and safe preparatory carriers, not a successful bound deployment. The revised campaign packet separates first publication into required M-14-C.3. C.1 remains the accepted opt-in binding/early-refusal boundary. The physical law in PROP-076 requires a pinned local project/settings/home observation, one cooperating-writer destination lock for alias spellings, rechecks at admission and commit, and honest partial truth after a possible write.

The safefs changes (`592241b72`, `50ccf4144`) retain no-follow handles for descendant projects and lock files. The pinned vibe-bin store (`7ce63a97d`, `09bd6fe74`) takes the common settings lock, pins `bin` and `store`, and checks their names around I/O. Bound state (`681b5f19f`), host admission (`2965bdd59`), and optional lock/checkpoint/inverse binding carriers (`93859cdf1`, `d0b458c53`) use the same operation identity. A missing or copied bound sidecar cannot be reconstructed by the legacy fallback. The provider adapter can plan and observe through pinned handles, but the incumbent transaction has not yet issued it an effect grant. Its published entry point still refuses bound apply before provider selection and state creation.

Review found two gaps in the initial candidate: the grant compared generation only with its own captured value, and the final recheck omitted named `bin`/`store`. Commit `397f11456` makes preflight, lock acquisition and final observation require a separately supplied current host generation; the final observation checks both named children. Tests exercise a changed generation with unchanged roots, two alias spellings contending for the same physical lock, disjoint settings roots proceeding together, alias retargeting, and named `bin` replacement. C.3 must connect these parameters to a real owner source, call the final observation after effects, and classify post-write drift as partial/uncertain with the intent retained. Until then these APIs are only a fence foundation.
