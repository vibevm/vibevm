After a possible provider write and before the receipt, failures return `BoundPublicationUncertain` and retain the intent. After a receipt is durable, cleanup/final-observation failures use `BoundCommitCleanupUncertain`, which does not falsely claim that the intent must still exist. A test forces generation drift after real payload/launcher/pointer publication and observes real destination bytes, a retained bound intent, no receipt and `BoundPublicationUncertain`.
