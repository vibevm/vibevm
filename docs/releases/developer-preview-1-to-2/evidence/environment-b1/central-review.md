The typed producer hashes the normalized authored definition and constraints, exact selected package and external closure inputs, configuration bytes, and an explicitly selected executor/produced-runtime/emitted-code role with concrete OS/architecture/ABI/libc facts. `Any` is checked as a constraint; changing only the selected target, target role, package bytes, configuration bytes or output payload changes the appropriate digest. The wire validator compares generated exact-lock coordinates to independently supplied typed selection and capture bytes before accepting the digest, and returns no file or effect grant.
