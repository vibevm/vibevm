# M-14-B work-package review

The accepted B.1 [exact format review](environment-b1/central-review.md) and B.2 [legacy evidence review](environment-b2/central-review.md) share one PROP-076 environment identity model. B.1 adds separate selected lock and realized generation digest recipes, explicit build/runtime dependency roles, target path/metadata policy and six registered epoch-one request/value/receipt/error roots. Its ExactLock wire validator replays the typed pure producer against supplied captured package, backend and configuration bytes. B.2 preserves old package/artifact record meanings and supplies typed missing-input and substitution decisions. Neither child rewrites the incumbent lock, artifact store or package resolver as an environment owner.

The compatibility boundary is explicit. An old `sha256:` package hash remains readable but never becomes recipe-one proof by renaming. A recipe-one exact lock is minted only from typed selected inputs and the selected target role/platform; an opaque A.1 `LockId` stays opaque. An artifact record's historical verified status does not assert current output bytes. Source URL, registry, Git ref/commit, mirror and cache location remain provenance or transport, not content identity. A prefix-bound payload cannot move to a changed prefix without a separately validated relocation owner. Linux, macOS and Windows target roles are representable; macOS lexical path comparison grants no physical APFS/HFS alias guarantee, and unsupported Windows ACL/special metadata cannot be silently omitted.

The selected B.1 checks passed 10 pure core, 1 macOS path, 2 wire semantic and 3 wire contract cases plus clean codegen; B.2 passed 4 pure legacy and 3 lifecycle artifact-reader cases. The global `wire-diff` check failed on pre-existing index `repomd.json` journal-projection drift, outside this work package's changed paths, and is not credited as a pass. Neither child used mutation or workspace-wide tests. Their reviews name the exact retained logs and hashes.

M-14-B is accepted as a bounded source/schema/reader package. Actual environment definition resolution, delivery from mirror/cache with durable `served_by`, full physical capture authentication, generation receipt publication, and target effects remain later M-15 and M-14-C work. M-14 milestone release-impact reconciliation remains open; this parent decision neither proves native platform execution nor authorizes public Git publication.
