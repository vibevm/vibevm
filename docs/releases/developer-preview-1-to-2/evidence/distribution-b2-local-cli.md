# M-07-B.2 local smoke command — candidate evidence

`cargo xtask dist prepare-local --out-dir <directory>` prepares a local 1.1.0 publication subject from the five exact bundle ZIPs, their fragments and bootstrap artifacts. It verifies each ZIP and stages its executable into a fresh temporary home before attempting the native `vibe --version` probe. The command saves a content-addressed `distribution-smoke-report/e1` file under the output directory and writes those exact saved JSON bytes to stdout. It does not invoke the existing GitHub Release `dist prepare` path or publish anything.

Smoke is the default for every target. `--skip-smoke-target <target>` may be repeated only with one nonblank `--skip-reason <reason>`; an unknown or duplicate target and an absent reason fail before opening output. A skipped target still needs a valid bundle, but has no launch, tested digest or runner reference in its report row. A report with any skipped or unavailable row remains not apply-ready under the default `distribution-smoke/e1` policy. The command accepts only the mutable 1.1.0 version.

Root reviewed `cb1455412` and ran `cargo test --locked --offline -p xtask --bin xtask dist::prepare_local_cli_tests` (2/2) and `cargo test --locked --offline -p xtask --bin xtask dist::capture::tests::tests_smoke` (3/3). The latter includes the exact persisted stdout bytes, damaged ZIP refusal with a skip, and a skip that does not become a false successful launch. These synthetic tests do not prove macOS or Windows execution. Separate real native Linux GNU and musl receipts are [GNU](distribution-b1-native-linux-gnu.md) and [musl](distribution-b1-native-linux-musl.md), each for its named earlier committed source candidate. The five-bundle final-candidate native matrix and M-07-B parent acceptance remain open.
