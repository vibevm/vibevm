# M-16-B.3 scoped review

Reviewed implementation subjects: `d536041d5` (four permanent desired-law anchors), `a22c21a66` (registered strict frame), `f0671d95d` (bounded byte codec), `ac7d28bcb` and `49a9ffe3d` (negotiation and required planner epochs), `919522ad3` (neutral orchestrator exchange), `a7d281bff` (MCP adapter over that exchange), `c45c64ae0` (on-demand pure runner), and `7f650331b` (documentation from executable source). The intervening task-packet changes and authority-map repair do not establish machine-session behavior.

The separate codec checks its four-byte declared length before allocation, then validates UTF-8, JSON, generated shape and frame epoch. EOF closes the session. The state machine binds only surface-supplied `ServerContext` values; it issues connection-local IDs and advertises API `1`, raw byte offsets, five registered epoch-one schemas, and false streaming/replay/control flags. Unknown, foreign, unavailable or duplicate IDs refuse. HOME/container remain explicitly unavailable. The runner takes supplied reader/writer ownership, admits only the pure migration planner, and passes the same validated envelope exchange used by the retained MCP tool. An output failure retains the unsent response as diagnostic evidence and closes before the next request.

The [framed-session developer document](../../../../machine-api/framed-session.md) records the actual frame, handshake, context boundary, one admitted route, unsupported capabilities and legacy MCP `2024-11-05` line transport. The selected test panel is recorded in [verification.md](verification.md): 25 passed, zero failed. No permanent daemon, LSP/DAP adapter, IDE plugin or MVP was added. This is acceptance of the B.3 bounded transport/handshake atom only, not acceptance of full M-16 machine-operation coverage, an executable CLI frame entry, effectful jobs or public DP2 publication.

Release-impact and finite source capture for the whole M-16-B work package still need reconciliation before parent acceptance. The frame schema remains mutable epoch one in package version 1.1.0; no product/package version increment or public Git publication occurred.
